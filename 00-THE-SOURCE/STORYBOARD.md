# STORYBOARD ·《源 · THE SOURCE》（66 s · 120 BPM · 132 拍）

坐标系：一切以「拍」为单位。120 BPM → 1 拍 = 0.5 s = **60 帧 @120fps**（整数，卡点地基）。
所有镜头 / 文字 / 音效共用 `src/timeline.mjs` —— 画面切在哪一拍，鼓就落在哪一拍。

## 一个问题，一个答案

> **「一行代码，能走多远？」**
> 一行真实源码 → 炸成五千个字形 → 拼成第一帧 → 四代模型一代比一代会拍 →
> 28 部片子组成一颗球、一面墙 → 骤停：「它们，是怎么做出来的？」→
> **通 通 开 源**（每个字由几百个作品帧拼成）→ 穿过一帧，钻进它的源码 →
> 45,558 行代码、515,858 字复盘、仓库地址 → 「下一行，由你来写。」（第 45,559 行）

## 画面系统

- **母题：代码字形解码。** 精灵着色器里的 `uGlyph`：把画面切成等宽字符网格，每格取视频中心色，用**该作品自己的源码字符**当笔画；一道对角扫描波把"代码"逐格解码成"画面"，前沿发光、字符乱跳。全片几乎每个新镜头都从自己的源码里长出来 —— 这就是「通通开源」的视觉证明。
- **3D**：自写 mat4 透视相机；窗口塔 / 世界环 / 作品球 / 文件瀑布都是真 3D。
- **后期链**（全部自写 GLSL）：HDR 缓冲 → 5 级泛光 → 抖动 / 旋转 / 镜头畸变 → 径向色差 → 软肩色调 → 暗角 → 亮度加权颗粒 → 闪白 → 2.39 遮幅 → 抖色。
- **转场库**（`FS_TRANS`）：slice / zoom / shatter(Voronoi) / ink(fbm) / pixel / rgb / whip，另有精灵级的 glyph 解码。
- **HUD**：REC · `t = xx.xxx s  f xxxxx  render(t)` · 底部 28 槽作品轨（作品首次出场时按模型色点亮）。
- **模型色**：KIMI `#3CF0C8` / SWE `#7CC4FF` / GPT `#A98BFF` / OPUS `#FF7A3D` / SKILL `#FFD166`。

## 配乐系统（`audio/score.py`）

D 小调 · 120 BPM。织体密度 = 段落能量；鼓、贝斯、pad、超锯 stab、十六分琶音、超锯主旋律、钢琴全部 numpy 合成（PolyBLEP 锯齿波去混叠）。
SFX 两层：合成（boom / braam / riser / 滚奏 / 钟 / 心跳 / 颗粒…）+ 仓库源码包里的真实音效（impact-bass、whoosh-cinematic、key-press、sfx_1143 冲击、sfx_2608 吸入、sfx_1088 倒带…），**按峰值对齐拍点**。
混音：kick 侧链 → 噪声 IR 卷积混响 → 母线胶水压缩 → 软削波 → 4 ms 前视限幅；磁带骤停在总线上做变速重采样。
