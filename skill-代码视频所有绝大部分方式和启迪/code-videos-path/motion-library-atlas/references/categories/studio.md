# 专业工具与资产

DCC、场景交换与合法可复用资产。

## 先辨别这类能力

资产、作品、软件和网站 API 的许可证是不同层；执行第三方脚本前审查。

## 成片时间与导出

DCC 使用场景帧与缓存，资产工具记录配置和原始文件。GLB / 序列帧 / EXR / 剪辑交换文件。

## 反平庸提醒

用更多工具不是目标；先找能降低当前镜头风险的那一个。

## 资源索引

- [Blender](../libraries/blender/README.md)：完整的建模、动画、灯光、摄影、渲染与合成环境。
- [Blender Python API](../libraries/blender-python/README.md)：用 bpy 访问场景数据、属性、操作器和渲染。
- [MCP for Blender](../libraries/blender-mcp/README.md)：将 AI 工具调用与 Blender 操作连接起来的第三方项目。
- [glTF Transform](../libraries/gltf-transform/README.md)：读取、优化和修改 glTF / GLB 资产。
- [OpenTimelineIO](../libraries/otio/README.md)：描述剪辑的片段、时间、轨道和媒体引用。
- [OpenUSD](../libraries/usd/README.md)：面向大型三维场景组合和跨工具协作的描述体系。
- [Poly Haven](../libraries/polyhaven/README.md)：提供 HDRI、纹理和模型资源，可改善场景基础质量。
