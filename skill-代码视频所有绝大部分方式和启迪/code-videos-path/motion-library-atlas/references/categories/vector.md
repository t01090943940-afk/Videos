# 矢量与手绘

轮廓、蒙版、笔触与形变的工具集合。

## 先辨别这类能力

核对路径身份、方向、孔洞、viewBox 与中间帧。

## 成片时间与导出

形状与笔触先准备，运动由 t 或受控时间线求值。SVG 渲染或 Canvas 捕获。

## 反平庸提醒

随机手绘每帧重生成会变成闪烁，不是质感。

## 资源索引

- [SVG.js](../libraries/svgjs/README.md)：为 SVG 图形、属性和结构操作提供对象化接口。
- [Flubber](../libraries/flubber/README.md)：为二维轮廓之间的形变生成中间形状。
- [Paper.js](../libraries/paper/README.md)：提供 Canvas 上的矢量场景与路径几何操作。
- [Two.js](../libraries/two/README.md)：面向二维图形的场景 API，可使用多种渲染后端。
- [Rough.js](../libraries/rough/README.md)：生成带手绘感的线条、形状和填充。
- [Rough Notation](../libraries/rough-notation/README.md)：为 DOM 元素加手绘感高亮、下划线和括号。
- [Vivus](../libraries/vivus/README.md)：沿 SVG 路径做线稿描绘式动画。
- [Perfect Freehand](../libraries/perfect-freehand/README.md)：把带压力的输入点转成具有笔锋的轮廓。
- [GSAP MorphSVG](../libraries/morphsvg/README.md)：在 SVG 路径之间建立点对应并插值形状。
- [GSAP DrawSVG](../libraries/drawsvg/README.md)：控制 SVG 描边的可见区间，形成线稿揭示。
- [SVG](../libraries/svg/README.md)：基于文档结构描述矢量图形、蒙版和滤镜。
