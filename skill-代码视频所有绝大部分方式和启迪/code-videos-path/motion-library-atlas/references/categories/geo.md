# 地图与空间数据

用位置、路线和视角讲述地理关系。

## 先辨别这类能力

核对底图与数据许可；标记示意地图；保留必需署名。

## 成片时间与导出

显式路径与地图时钟；等待关键瓦片、字形及地形。固定视口捕获 → 视频。

## 反平庸提醒

持续飞越不能代替地理解释，透视也可能误导面积。

## 资源索引

- [MapLibre GL JS](../libraries/maplibre/README.md)：用 WebGL 显示矢量地图并控制相机与图层。
- [Mapbox GL JS](../libraries/mapbox/README.md)：提供地图显示、样式与摄影机动画能力。
- [deck.gl](../libraries/deck/README.md)：以图层组织大规模数据可视化，常与地图协作。
- [CesiumJS](../libraries/cesium/README.md)：用于地球、地形和时空数据的三维可视化。
- [Leaflet](../libraries/leaflet/README.md)：轻量二维交互地图工具，适合注释与路线。
