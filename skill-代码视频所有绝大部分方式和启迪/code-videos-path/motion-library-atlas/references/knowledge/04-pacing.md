# 节奏：不是越快越好

“AI 喜欢慢动画”是值得检验的生产现象，不是所有模型的定律。没有本项目的跨模型实验，不能声称已经量化证明。

## 为什么默认动画容易拖慢

一种可能原因是：模型选择了低风险的淡入、停留、淡出模板，却没有给动作设置信息任务。另一种是串行等待每个元素完成，导致时间被不断叠加。还有一种是只看代码或几张图，没有观看完整片段。这些是排查假设，需通过结果验证。

## 把时间预算写清楚

先标记信息出现、观众理解、关键重音、状态改变和离开的时刻。入场不是必须独占一整段时间，可以与上一项收束重叠。停留若用于阅读或感受，是有效时长；没有信息任务的空等才需要削减。

不在所有项目中强制“6–15 帧入场”或“最多 12 帧静止”。文字长度、画幅、观众、语速和视觉复杂度不同。给一个明确的片段预算，再解释每个动作为何占用这些时间。

## 三种实际检查

只听声音，检查旁白与静默是否成立。静音观看，检查焦点是否清楚。完整观看，检查声音重音和视觉动作是否互相支持。自动 motion map 可以发现低运动区，但不能据此认定“这里没有信息”。
