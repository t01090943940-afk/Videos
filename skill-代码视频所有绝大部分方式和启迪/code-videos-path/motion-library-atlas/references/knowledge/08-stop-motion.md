# 定格风格，不只是降帧

传统定格是逐次调整实体并拍摄图像；程序三维可以模仿离散姿态的节奏，但这并不等于实体拍摄，也不意味着只需把帧率改低。

## 展示帧率与姿态节拍

视频可以保持 30 或 60 帧输出，而角色姿态以较低频率更新。摄影机、灯光、纹理和角色不必全部使用同一采样率。物理模拟可以高频固定步长计算，再把结果按需要展示。

## 更重要的部分

姿态要有可读轮廓，动作要有预备、关键接触和收束。材质与布光要支持微缩或手工质感。随机抖动、随机曝光和随机位移不是万能风格滤镜，容易破坏连续性。

## 一个小型边界实验

同一场景做连续插值、离散姿态、离散姿态加精心调整的关键姿态三个版本。不要同时改变全部材质和灯光，否则无法区分提升来自哪里。观察脚底滑动、手物接触和镜头可读性。

本地 stop-motion 案例只展示了简化积木角色的采样与站位，不宣称完成专业骨骼、碰撞或实体定格制作。
