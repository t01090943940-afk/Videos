# 声音的四种材料

程序合成、MIDI 编排、合法音频素材、外部生成式音乐服务，分别解决不同问题。Tone.js 与 Web Audio 是声音工具，不等于一个能理解全部音乐风格的作曲模型。

## 先决定声音的功能

旁白提供信息；音效表示接触、转折或反馈；配乐建立节奏和情绪；静默让信息停留。不能把音量跳动作为每个图形都运动的理由。

## 声画同步

最终音轨可以离线计算，再按确定时间与视频合成。实时设备播放存在延迟，浏览器还可能要求用户手势解锁声音。用可检验的事件时间对应画面，不凭预览主观认为“差不多”。

## 授权与真实性

素材与模型服务分别核查商用条款、署名、人物声音权利和衍生限制。不要未经授权模仿私人声音，不把合成声音假称录音。本工作站不调用任何收费音乐或语音接口。

本地 sound-grid 提供原创短音序试听及 WAV；它通过代码生成 PCM，再使用 Web Audio 播放，不冒充 Tone.js 调用或 AI 作曲服务。

[Tone.js](https://tonejs.github.io/)；[Web Audio](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API)。
