# 证据等级：别把想象写成实测

本项目分开记录来源证据与运行证据。漂亮画面、官方定位、成功安装、渲染通过、真实业务稳定，是不同结论。

## 四种可使用的说法

“入口索引”：找到官方或作者入口，尚未深入检查。

“核心定位已核对”：阅读了官方资料，支持所列的核心用途；不表示逐项审计所有 API。

“本地原理演示”：使用另一种实现说明视觉机制，不能证明被关联库的兼容性、性能或 AI 成功率。

“实际运行”：明确库/API、版本、环境、输入、代码、输出和测试范围。单个示例仍不能代表整库或所有模型。

## 当前数据的空值有意义

模型评分、弱模型成功率、跨模型比较与生产成本都保留未知。没有运行多个模型，不得填写看似精确的分数。候选组合也不是兼容性承诺。工作台允许用户录入自己的实验记录，但不会偷偷把记录当成已经审查的研究结论。

## 该留存什么

至少记录日期、模型与模式、输入、资源版本、Skill 版本、迭代次数、运行环境、代码版本、画幅、帧率、输出文件和失败原因。截图证明一个时刻被观察，完整视频用于观察时间关系，音轨还需单独听。自动几何检查不等于自动理解审美。

同一时刻重复渲染的像素一致性，应限定到测试环境。跨浏览器、字体、GPU、编解码器可能不同；不要扩大结论。
