# MG 与“AE 级”到底在比较什么

MG 可理解为图形设计在时间中的表达，包括文字、图形、照片、数据与空间的变化。这里采用的是工作性解释，不把某个软件当作风格本身。

## 别用软件名代替能力清单

所谓“AE 级”可以指图层合成、遮罩、文字动画、关键帧曲线、滤镜、追踪、抠像、插件或精细人工修整。完成其中一种视觉效果，不等于替代整个软件与所有工作流程。AE 自身也包含脚本与表达式。[Adobe 表达式说明](https://helpx.adobe.com/after-effects/desktop/work-with-expressions/expression-basics/expression-language.html)。

## 动作的价值来自它改变了什么

一种有用的判断是：动作是否引导焦点、解释关系、揭示结构、表示状态改变、连接镜头，或者建立情感。只有装饰也可以，但应是有意识的风格决定，而不是模型默认加上的漂浮。

Vox 式的编辑性拼贴也不等于纸纹滤镜。文案论点、资料图像、信息层级、剪辑与视觉比喻共同工作。把参考拆成蒙版、平面层、标注、路径、构图和节奏，才能反向找到工具。

## 安全、平庸、创新不是同一条轴

技术安全表示可重复、可修改、可导出。视觉平庸表示在当前任务中缺少选择与表达。创新表示相对于参考和目标产生了有效的新组合。三者不能用一个星级吞并；一个静止特写可能比十种转场更好。
