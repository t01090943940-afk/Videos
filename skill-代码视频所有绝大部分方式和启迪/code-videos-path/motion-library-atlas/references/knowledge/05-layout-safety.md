# 重叠、越界与漏检

首先区分有意遮挡和意外覆盖。拼贴、蒙版、景深与图层合成本就会重叠；问题是关键内容是否被非预期地遮住，以及对象关系是否改变了意义。

## 静态检查不足以看懂动画

需要检查开始、结束、运动中间和转场两侧。文字可能只在 overshoot 时越界，卡片可能只在布局交换时穿过标题。对短动作增加采样密度，不能只用每秒一张图。

## 文字边界

先等待真实字体就绪，再测布局。检查最长标题、中文标点、英文长词、动态数字和多行字幕。屏幕边界留白只是一个构图参考，不是对所有项目统一的法律。相互覆盖应结合图层用途和文字重要性判断。

## 3D 的四个不同检查

可见网格互穿、碰撞体不匹配、角色蒙皮穿透、摄影机进入物体或近裁剪，分别定位。物理引擎处理其配置的物理世界，不自动保证每个像素的接触正确。[Rapier 入门](https://rapier.rs/docs/user_guides/javascript/getting_started_js/)。

## 本工作站的边界

实验台安全区参考线只帮助人工查看构图。它不是自动语义重叠检测器。Playwright 的界面测试、帧哈希与截图检查也只证明报告里实际测试的范围，不证明每个案例都达到商业成片标准。
