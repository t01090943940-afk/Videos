# 能看到，不等于能打包再分发

运行库、Skill 文本、字体、模型、照片、音乐、官网作品和 API 服务条款是不同层。一个开源播放器不能转授它播放的动画资产；网站上的截图也未必受库代码许可证覆盖。

## 这个项目的做法

本地视觉示例主要使用原创程序几何，不抓取他人作品当作自己的案例。外部作品以来源入口导航，不绕过 iframe、跨域或下载限制。第三方代码保留通知；字体不随包分发。用户商用时仍需按实际使用内容核查条款。

Poly Haven 的资产采用 CC0，但网站文字、示例渲染与网站/API 使用有独立限制，不能从“资产可商用”推导出“可任意爬完整网站”。[官方许可与条款](https://polyhaven.com/license)。

## 外部技能与连接器

执行脚本前检查代码。下载资产、访问私人文件、调用付费模型、修改工程文件都要受用户授权。不要把示例 token、账户凭证或环境变量写进前端包。Blender MCP 是第三方连接器，不是 Blender 官方背书。[作者仓库](https://github.com/ahujasid/mcp-for-blender)。

本工作站默认本地运行，没有账户登录、广告追踪、远程代码执行或付费 API 按钮。
