# p5.js · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

让噪声流场变成逐渐聚拢的字形。

## 需要调用的能力

2D 绘画, noise, WEBGL, shader。

## 先检查什么

draw 的帧计数不是可靠视频时钟；随机、鼠标和实时输入需冻结。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

用明确 t 代替 frameCount 累积状态；固定 seed；将输入录制或参数化。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
