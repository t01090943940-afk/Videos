# Playwright

> 类型：自动化工具 · 分类：捕获与导出 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

操作浏览器、截图、测试并录制页面视频。

- 页面自动化
- 截图
- 视频记录
- 视觉测试

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：自动检查动画标题是否越界。
- [实验方向 02](./examples/02.md)：把真实产品操作录成素材，再交给合成层加镜头语言。

## 能力边界

录制主要是实时浏览器记录，不自动保证制作级逐帧时间；不能把鼠标操作本身当成剪辑。

## 使用建议（本词典编辑性判断）

- 视频渲染优先 seek 后截图；检查字体、媒体、控制台错误；给鼠标单独可见轨迹。
- 检查首尾帧、时长、可解码性与音画同步；成功退出不等于质量达标。

## 时间线与输出

明确视频时基与帧序号；录屏与逐帧渲染分开记录。

记录容器、codec、fps、采样率和像素格式。

## 组合候选

[ffmpeg](../ffmpeg/README.md), [webcodecs](../webcodecs/README.md), [mediabunny](../mediabunny/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 浏览器实时 60fps 不证明最终视频不掉帧或逐帧确定。

## 进一步辨别

### 拍网页与渲染视频

录制真实产品交互时，Playwright 很实用。制作确定性动画时，更直接的路线是让页面暴露目标时间，设置时间后截图，最后编码。两条路线都合理，但证据不能混用。

浏览器测试先确认页面无异常、资源已完成、字体稳定，再检查几何边界和关键画面。截图可证明某一帧被捕获，不能单独证明动作、声音和剪辑都正确。

[视频记录](https://playwright.dev/docs/videos) 与 [截图](https://playwright.dev/docs/screenshots) 分开查阅。本项目实际用浏览器测试验证界面与代表性画面，测试范围另存报告。

## 通用镜头提示词

```text
你正在制作一个代码视频镜头，而不是普通网页。请围绕「Playwright」研究 页面自动化, 截图, 视频记录 的表达可能。

创作输入：主题=[填写]；目标观众=[填写]；时长=[填写]；画幅=[填写]；旁白/素材=[填写]；参考画面=[填写]。

先读取该库官方文档：https://playwright.dev/docs/videos。确认版本，必要时只加载相关 Skill，不要盲目复制过时 API。
提出 2 个不同的视觉解释方案，说明每个动作承担的意义。优先考虑：自动检查动画标题是否越界。
选择方案后写出明确的时间点、主体、焦点和前后状态。不要默认把全部对象设置成缓慢淡入；阅读停留需有目的，运动节奏服从信息理解。
技术边界：录制主要是实时浏览器记录，不自动保证制作级逐帧时间；不能把鼠标操作本身当成剪辑。
接入建议：明确视频时基与帧序号；录屏与逐帧渲染分开记录。组合候选：ffmpeg, webcodecs, mediabunny，尚未验证，先小样确认。
先输出可运行的代表镜头，再渲染检查首帧、动作中间、转场两侧和尾帧。检测文字越界、非意图遮挡、资源缺失与不同步；3D 另检镜头及可见网格穿透。
交付源代码、运行方式、素材及版本清单、实际预览与已知限制。把“官方能力”“自己的设计建议”“实际测试结果”分开报告。不要虚构质量分、模型成功率或测试截图。
```
