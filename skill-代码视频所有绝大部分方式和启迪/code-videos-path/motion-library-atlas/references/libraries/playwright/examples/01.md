# Playwright · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

自动检查动画标题是否越界。

## 需要调用的能力

页面自动化, 截图, 视频记录, 视觉测试。

## 先检查什么

录制主要是实时浏览器记录，不自动保证制作级逐帧时间；不能把鼠标操作本身当成剪辑。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

视频渲染优先 seek 后截图；检查字体、媒体、控制台错误；给鼠标单独可见轨迹。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
