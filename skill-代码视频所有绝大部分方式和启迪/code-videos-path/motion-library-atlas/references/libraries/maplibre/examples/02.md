# MapLibre GL JS · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

以同一尺度对比两片区域，避免视角暗示错误面积。

## 需要调用的能力

地图图层, 相机飞行, 地理数据, 样式。

## 先检查什么

地图数据、瓦片和字形服务各有许可与网络依赖；不是所有内容可离线分发。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

固定地图样式与数据快照；等待 tiles 就绪；拍摄路径与地图数据分离。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
