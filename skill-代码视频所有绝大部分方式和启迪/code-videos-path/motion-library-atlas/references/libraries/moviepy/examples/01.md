# MoviePy · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把实验结果图片和旁白拼成一组可批量更新的解释视频。

## 需要调用的能力

裁剪拼接, 合成图层, 音轨处理, 函数式视频帧。

## 先检查什么

大型逐帧 Python 合成可能较慢；v1 与 v2 的导入与 API 存在差异。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

锁定版本并缓存昂贵图层；将复杂视觉先渲染成素材再合成。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
