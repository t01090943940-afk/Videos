# Remotion · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把一段旁白拆成可修改的字幕与图表镜头，保留同一视觉身份。

## 需要调用的能力

帧驱动组件, 序列与合成, 音视频编排, 程序化渲染。

## 先检查什么

普通 React 动画的真实时钟不能自动变成视频时间；商用许可需按团队和用途核查。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

把视觉状态从 frame 推导；等待字体及媒体就绪；固定分辨率并检查关键帧。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
