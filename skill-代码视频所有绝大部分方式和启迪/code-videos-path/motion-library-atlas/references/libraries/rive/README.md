# Rive

> 类型：设计 / 运行时 · 分类：角色与动画资产 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

以动画和状态机连接设计工具与实时交互。

- 状态机
- 输入
- 时间线
- 矢量运行时

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让角色表情、视线和提示气泡跟随旁白状态。
- [实验方向 02](./examples/02.md)：复用同一交互角色生成多个功能演示片段。

## 能力边界

复杂作品通常来自设计资产；交互状态机需要可重放输入才能用于固定成片。

## 使用建议（本词典编辑性判断）

- 保存状态机输入事件；等待资产载入；逐个验证字体和渲染后端。
- 动画资产、字体、贴图和 runtime 分别核对版本及授权。

## 时间线与输出

暂停自动播放；固定帧或重放状态输入事件。

运行时捕获 → 合成。

## 组合候选

## 常见平庸与失败模式

- 引入现成资产不代表可以声称 AI 从零制作了角色动作。

## 进一步辨别

### 状态机进入固定时间的视频

交互作品通常根据输入事件改变状态。要成为可重拍镜头，需要保存输入何时改变以及如何初始化，而不只是给最后的播放时间。

先检查原始资产中哪些动作已经存在，再决定 AI 的工作是选择与编排，还是创作新资产。使用成熟资产是有效方法，但要如实归属制作来源。

[Web runtime](https://rive.app/docs/runtimes/web/web-js) 是运行接口。最终画面的好坏取决于资产本身、状态编排与合成，不应把它全部归因于模型。
