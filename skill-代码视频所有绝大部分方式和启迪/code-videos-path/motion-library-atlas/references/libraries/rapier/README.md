# Rapier

> 类型：物理引擎 · 分类：物理与约束 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

提供二维与三维刚体、碰撞体和约束模拟。

- 刚体
- 碰撞体
- 关节
- 连续碰撞检测

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让工地钢管落下、碰撞、停稳成为因果镜头。
- [实验方向 02](./examples/02.md)：用关节约束展示简单机械装置的运动范围。

## 能力边界

不是对所有可见几何的自动防穿模；蒙皮、布料和错误碰撞体仍会出错。

## 使用建议（本词典编辑性判断）

- 固定步长；设置 collider 尺寸与单位；高速物体核查 CCD；烘焙再逐帧采样。
- 验证碰撞体、CCD、关节范围、接触容差；烘焙不代表网格绝不会交叠。

## 时间线与输出

固定 dt 与初始状态，离线模拟并采样；不要把求解器当随机 seek。

物理状态 → 渲染器 → 视频。

## 进一步辨别

### 物理边界与动画边界

求解器接收的是碰撞体，不是自动理解所有画面模型。若人物鞋底与地面看上去穿透，可能是网格和 collider 对齐的问题；若高速小物体穿墙，可能需要检查步长和 CCD。

建议最小实验由静态地面、一个动态刚体和一个接触事件组成。记录单位、dt、重力、碰撞体尺寸、材质参数以及库版本，再加复杂度。

定格风格只改变展示姿态的采样节奏，不应让物理求解也随意变成 12 次每秒。可以高频固定步长模拟，再按艺术节奏展示缓存状态。
