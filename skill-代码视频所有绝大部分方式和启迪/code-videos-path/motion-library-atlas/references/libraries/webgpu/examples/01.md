# WebGPU · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

以计算粒子形成可变形的数据雕塑。

## 需要调用的能力

render pipeline, compute, buffers, WGSL。

## 先检查什么

设备与浏览器支持不可假设；不能把 WebGL shader 原样搬过去。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

做能力检测和降级；区分 CPU 时间与 GPU 完成；控制显存使用。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
