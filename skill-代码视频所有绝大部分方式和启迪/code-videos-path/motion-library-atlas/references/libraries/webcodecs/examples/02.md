# WebCodecs · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把 GPU 绘制结果压成预览文件并记录精确时间戳。

## 需要调用的能力

VideoFrame, VideoEncoder, AudioData, 时间戳。

## 先检查什么

编码器不等于 MP4 muxer；编解码支持和安全上下文需检测。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

检测支持；及时 close 帧；处理背压；用独立封装器写容器。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
