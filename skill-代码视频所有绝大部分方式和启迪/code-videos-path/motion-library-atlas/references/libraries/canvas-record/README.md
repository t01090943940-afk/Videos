# canvas-record

> 类型：录制库 · 分类：捕获与导出 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

围绕 Canvas 动画输出组织帧捕获与编码。

- Canvas 捕获
- 编码适配
- 动画记录

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把生成艺术草图导出为短循环。
- [实验方向 02](./examples/02.md)：给同一动态海报生成多个尺寸的测试片。

## 能力边界

具体后端支持、浏览器限制和音频路线需要核对。

## 使用建议（本词典编辑性判断）

- 测试所选编码后端；逐帧控制内容；区分实时录制和离线采样。
- 检查首尾帧、时长、可解码性与音画同步；成功退出不等于质量达标。

## 时间线与输出

明确视频时基与帧序号；录屏与逐帧渲染分开记录。

记录容器、codec、fps、采样率和像素格式。

## 组合候选

[ffmpeg](../ffmpeg/README.md), [playwright](../playwright/README.md), [webcodecs](../webcodecs/README.md), [mediabunny](../mediabunny/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 浏览器实时 60fps 不证明最终视频不掉帧或逐帧确定。
