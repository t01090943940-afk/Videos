# TypeGPU

> 类型：GPU 工具库 · 分类：着色与后期 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

在 TypeScript 工作流中组织 WebGPU 数据和着色逻辑。

- 类型化 GPU 数据
- WebGPU 辅助
- 着色器组织

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：将一组可控参数变成实时材质实验台。
- [实验方向 02](./examples/02.md)：用并行计算生成复杂的程序化运动背景。

## 能力边界

不能消除 GPU 与 WebGPU 支持限制；API 演进需跟随官方文档。

## 使用建议（本词典编辑性判断）

- 固定版本；先通过小型 shader 用例；把高层图形设计与 GPU 实现分开。
- 检查编译、长宽比、颜色空间、设备支持、内存和上下文丢失。

## 时间线与输出

显式时间 uniform；反馈效果需保存状态或预计算。

framebuffer/Canvas → 序列或编码。

## 组合候选

[webgl](../webgl/README.md), [gl-transitions](../gl-transitions/README.md), [pixi-filters](../pixi-filters/README.md), [postprocessing](../postprocessing/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 全屏炫光会遮蔽主体；转场必须有方向或形状联系。
