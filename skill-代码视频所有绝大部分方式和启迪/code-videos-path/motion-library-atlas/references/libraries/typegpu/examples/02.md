# TypeGPU · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

用并行计算生成复杂的程序化运动背景。

## 需要调用的能力

类型化 GPU 数据, WebGPU 辅助, 着色器组织。

## 先检查什么

不能消除 GPU 与 WebGPU 支持限制；API 演进需跟随官方文档。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

固定版本；先通过小型 shader 用例；把高层图形设计与 GPU 实现分开。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
