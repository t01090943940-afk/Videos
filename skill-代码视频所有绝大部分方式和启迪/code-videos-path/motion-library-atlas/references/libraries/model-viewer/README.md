# <model-viewer>

> 类型：Web 组件 · 分类：三维与摄影 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

以较少代码展示 glTF/GLB 模型，适合产品与展示页面。

- 模型展示
- 相机控制
- 热点
- 动画播放

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把真实产品模型作为画面中央，外部叠加编辑性注释。
- [实验方向 02](./examples/02.md)：同一个模型用三个机位展示关键结构。

## 能力边界

不等于完整虚拟片场；复杂多角色叙事应使用场景引擎。

## 使用建议（本词典编辑性判断）

- 固定相机目标与环境；等待模型加载；确认播放时间可被所用版本控制。
- 分清米制尺寸、坐标朝向、碰撞体和可见网格；检查镜头穿物与近裁剪。

## 时间线与输出

相机、姿态与灯光都受显式 t 驱动；模拟提前烘焙。

WebGL 帧或 DCC 渲染序列 → 合成。

## 组合候选

[three](../three/README.md), [drei](../drei/README.md), [rapier](../rapier/README.md), [blender](../blender/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 推拉摇移应改变理解；不停绕场不等于电影感。
