# Motion Canvas · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

将细胞运输过程拆成进入、结合、释放三个解释节拍。

## 需要调用的能力

生成器编排, 信号与补间, 矢量场景, 旁白时间点。

## 先检查什么

不是通用非线性视频剪辑器；生成器历史状态不能随意假设为纯函数。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

利用框架自己的时间线与播放控制；把讲解步骤拆成有名字的段落。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
