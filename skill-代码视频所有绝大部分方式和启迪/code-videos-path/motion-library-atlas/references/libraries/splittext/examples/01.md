# GSAP SplitText · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

先按词强调论点，再将字母作为形状完成转场。

## 需要调用的能力

字符拆分, 词行分组, 响应式重拆, 与 GSAP 配合。

## 先检查什么

拆分不是排版设计；中文、换行、无障碍和字体加载会影响结果。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

在字体完成后拆分；布局改变后重新拆分并回收旧节点；提供完整可读文本。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
