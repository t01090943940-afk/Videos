# React Bits

> 类型：组件集合 · 分类：前端视觉与调参 · 研究快照：2026-09-24
> 证据：入口索引。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

收集 React 视觉、背景和文字等交互组件。

- 文字效果
- 交互背景
- UI 动效
- React 组件

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把一个背景效果限定为章节转折的 2 秒强调。
- [实验方向 02](./examples/02.md)：用一项文字效果建立标题语法，而不是每个镜头换一种。

## 能力边界

很多示例依赖实时鼠标、滚动或 GPU；可用源码不等于全部案例可直接成片。

## 使用建议（本词典编辑性判断）

- 逐例审查依赖、许可和输入；将交互参数变成显式时间轨迹。
- 交互示例改编要核对尺寸、依赖、字体、授权与降级。

## 时间线与输出

将鼠标、滚动与 hover 记录或参数化为可重放轨迹。

页面捕获 → 剪辑与标注。

## 组合候选

[motion](../motion/README.md), [gsap](../gsap/README.md), [playwright](../playwright/README.md), [waapi](../waapi/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 不能把登陆页的慢滚动直接当成紧凑视频。

创作输入：主题=[填写]；目标观众=[填写]；时长=[填写]；画幅=[填写]；旁白/素材=[填写]；参考画面=[填写]。
