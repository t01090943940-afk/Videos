# Canvas 2D

> 类型：浏览器 API · 分类：二维场景 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

浏览器原生即时绘图表面，可直接从时间计算每一帧。

- 路径
- 文字
- 图像
- 像素与合成

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：做可逐帧检查的纸片排版与遮罩。
- [实验方向 02](./examples/02.md)：用一个显式时间函数驱动科学图形和字幕。

## 能力边界

没有自动场景图、选择框或摄像机；文字和高 DPI 需自己管理。

## 使用建议（本词典编辑性判断）

- 固定画布尺寸；每帧重设 transform；把资源加载完成作为渲染门槛。
- 分辨率、pixel ratio、滤镜区与资源就绪必须固定。

## 时间线与输出

禁用 ticker 累加或从固定初态重建每个时间。

Canvas 图像序列 / WebCodecs + 封装器。

## 组合候选

[pixi](../pixi/README.md), [gsap](../gsap/README.md), [ffmpeg](../ffmpeg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 大量图层运动应有主次，不能每一层同时争抢注意。
