# CSS Animations · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

让纹理与内容分开运动，保持阅读区域稳定。

## 需要调用的能力

keyframes, transform, opacity, clip-path。

## 先检查什么

不是所有属性都可平滑插值；纯 CSS 播放不等于准确视频时间线。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

优先明确 transform origin；通过 WAAPI 控制 CSS 动画时间，避免依赖负延迟猜帧。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
