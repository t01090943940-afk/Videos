# Manim Community · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把矩阵变换直接作用到网格与基向量，而非只播放公式。

## 需要调用的能力

MathTex, 几何对象, Transform, 坐标与绘图。

## 先检查什么

与 3b1b 的 ManimGL 分支不同；LaTeX、字体、渲染器依赖需准备，弱模型表现尚未实测。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

注明社区版及版本；先静态验证公式，再调变换对象和时间。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
