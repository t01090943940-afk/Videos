# Tone.js MIDI

> 类型：数据工具 · 分类：声音与节拍 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

读取和组织 MIDI 音符、轨道和时间信息。

- MIDI 解析
- 音符
- 轨道
- 时间

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让音符落点驱动不同图形层级。
- [实验方向 02](./examples/02.md)：将现有 MIDI 编排转成可修改的动态图谱。

## 能力边界

MIDI 不含录制好的声音；需要音源或合成器。

## 使用建议（本词典编辑性判断）

- 将拍数转换到秒时考虑 tempo map；保留音源与采样许可。
- 分开 BGM、旁白、音效与静默；控制响度、削波和版权。

## 时间线与输出

最终音轨用离线采样时间；实时播放只作预览。

WAV/音频数据 → 与视频混合编码。

## 组合候选

[tone](../tone/README.md), [web-audio](../web-audio/README.md), [ffmpeg](../ffmpeg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 音乐合成与 AI 作曲不是一回事，节拍不能覆盖旁白可理解性。
