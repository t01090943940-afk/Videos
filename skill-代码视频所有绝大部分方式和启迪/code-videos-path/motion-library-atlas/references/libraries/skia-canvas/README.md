# Skia Canvas

> 类型：Node 渲染库 · 分类：二维场景 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

在服务端使用类似 Canvas 的接口进行高质量二维绘制。

- 离屏绘图
- Canvas 接口
- 图像输出
- 路径排版

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：批量输出不同语言的字幕卡与章节图。
- [实验方向 02](./examples/02.md)：将同一套矢量图形渲染成高分辨率序列帧。

## 能力边界

不是浏览器 DOM；原生二进制依赖和平台支持需核实。

## 使用建议（本词典编辑性判断）

- 将字体与依赖版本固定；用小样比对浏览器与服务端的排版差异。
- 分辨率、pixel ratio、滤镜区与资源就绪必须固定。

## 时间线与输出

禁用 ticker 累加或从固定初态重建每个时间。

Canvas 图像序列 / WebCodecs + 封装器。

## 组合候选

[pixi](../pixi/README.md), [gsap](../gsap/README.md), [canvas2d](../canvas2d/README.md), [ffmpeg](../ffmpeg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 大量图层运动应有主次，不能每一层同时争抢注意。
