# Mermaid

> 类型：图解语法 · 分类：数据与图解 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

把文本描述转换为流程、序列与其他图解。

- 文本到图
- 流程图
- 序列图
- 图形生成

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：用结构化文字快速建立解释图草案。
- [实验方向 02](./examples/02.md)：将同一机制的不同分支依次显露。

## 能力边界

自动布局不等于优秀动态导演；动画和逐元素控制通常需额外处理。

## 使用建议（本词典编辑性判断）

- 先生成并检查静态图；给可动画元素稳定身份；复杂视觉转向专用绘制。
- 标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 时间线与输出

固定数据与对象身份，显式插值几何或视图信号。

SVG/Canvas 捕获 → 视频合成。

## 组合候选

[d3](../d3/README.md), [svg](../svg/README.md), [remotion](../remotion/README.md), [observable-plot](../observable-plot/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 高级图形不是把所有数字同时翻滚。
