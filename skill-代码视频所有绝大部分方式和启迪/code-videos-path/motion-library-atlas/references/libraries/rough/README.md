# Rough.js

> 类型：风格库 · 分类：矢量与手绘 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

生成带手绘感的线条、形状和填充。

- 手绘描边
- hachure 填充
- Canvas
- SVG

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：用手绘包围圈标出关键论据而不是堆装饰箭头。
- [实验方向 02](./examples/02.md)：把规整示意图变成白板解释，但保持数据位置准确。

## 能力边界

手绘质感不等于纸张拼贴；随机笔触若每帧重算会闪烁。

## 使用建议（本词典编辑性判断）

- 固定 seed；先生成稳定笔触，再对整体形状做动画。
- 核对路径身份、方向、孔洞、viewBox 与中间帧。

## 时间线与输出

形状与笔触先准备，运动由 t 或受控时间线求值。

SVG 渲染或 Canvas 捕获。

## 组合候选

[gsap](../gsap/README.md), [flubber](../flubber/README.md), [svg](../svg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 随机手绘每帧重生成会变成闪烁，不是质感。
