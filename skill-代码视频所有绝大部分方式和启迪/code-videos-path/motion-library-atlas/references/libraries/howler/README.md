# Howler.js

> 类型：声音库 · 分类：声音与节拍 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

简化音频播放、音频精灵和跨浏览器使用。

- 音频精灵
- 播放控制
- 音量
- 空间音频

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：为 UI 演示添加克制的操作反馈。
- [实验方向 02](./examples/02.md)：同一音效库服务不同镜头，保持音色一致。

## 能力边界

偏播放层，不是编曲或视频混音引擎。

## 使用建议（本词典编辑性判断）

- 预加载短音效；记录触发时间；最终成片用独立离线混音确认同步。
- 分开 BGM、旁白、音效与静默；控制响度、削波和版权。

## 时间线与输出

最终音轨用离线采样时间；实时播放只作预览。

WAV/音频数据 → 与视频混合编码。

## 组合候选

[tone](../tone/README.md), [web-audio](../web-audio/README.md), [midi](../midi/README.md), [ffmpeg](../ffmpeg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 音乐合成与 AI 作曲不是一回事，节拍不能覆盖旁白可理解性。
