# FFmpeg

> 类型：媒体工具 · 分类：捕获与导出 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

处理编码、转码、滤镜、合成和音视频封装。

- 编码
- 滤镜
- 音轨
- 帧序列

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：将浏览器输出的 PNG 序列编码成可发布的 MP4。
- [实验方向 02](./examples/02.md)：批量合成旁白、音效与片尾并保持总时长一致。

## 能力边界

不是视觉设计工具；编译选项和编解码器许可需按分发场景确认。

## 使用建议（本词典编辑性判断）

- 明确 fps、像素格式、音频采样率；用 ffprobe 验证结果而非只看退出码。
- 检查首尾帧、时长、可解码性与音画同步；成功退出不等于质量达标。

## 时间线与输出

明确视频时基与帧序号；录屏与逐帧渲染分开记录。

记录容器、codec、fps、采样率和像素格式。

## 组合候选

[playwright](../playwright/README.md), [webcodecs](../webcodecs/README.md), [mediabunny](../mediabunny/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 浏览器实时 60fps 不证明最终视频不掉帧或逐帧确定。
