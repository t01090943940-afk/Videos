# OpenTimelineIO

> 类型：工程交换 · 分类：专业工具与资产 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

描述剪辑的片段、时间、轨道和媒体引用。

- 剪辑结构
- 时间
- 轨道
- 格式适配器

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把镜头清单导出成可继续人工剪辑的时间结构。
- [实验方向 02](./examples/02.md)：将重渲染后的镜头重新对齐到原有剪辑。

## 能力边界

不是视频渲染器，通常不内嵌媒体；各剪辑软件适配能力不同。

## 使用建议（本词典编辑性判断）

- 先验证目标软件 adapter 支持哪些字段；不要用它假装完全保留 AE 效果。
- 资产、作品、软件和网站 API 的许可证是不同层；执行第三方脚本前审查。

## 时间线与输出

DCC 使用场景帧与缓存，资产工具记录配置和原始文件。

GLB / 序列帧 / EXR / 剪辑交换文件。

## 组合候选

[blender](../blender/README.md), [blender-python](../blender-python/README.md), [gltf-transform](../gltf-transform/README.md), [polyhaven](../polyhaven/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 用更多工具不是目标；先找能降低当前镜头风险的那一个。
