# HyperFrames · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把纸片拼贴、文字节奏和 3D 产品镜头放进一个合成。

## 需要调用的能力

HTML composition, seekable 时间线, 多动画运行时, 检查与渲染工具。

## 先检查什么

不是任意网页直接录屏就等价；具体 authoring contract 以当前官方文档为准。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

先读官方 animation skill 和项目规范；让 CSS、JS、媒体跟随同一显式时间。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
