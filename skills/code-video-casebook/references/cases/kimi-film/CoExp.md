# 《月之暗面 · KIMI》纯代码视频制作复盘

> 56s / 1920×1080@30fps / 2.35:1 遮幅 / 全程 numpy+PIL 逐像素渲染、numpy 逐样本合成音频、ffmpeg 编码。
> 本文按真实制作过程复盘，供下次同类项目直接复用。代码文件：`kit.py`（渲染引擎）/ `scenes.py`（六幕）/ `score.py`（合成器+编曲）/ `film_par.py`（并行渲染）。

## 一、创作思路

### 1. 需求 → 叙事结构的拆解

用户关键词 → 设计决策的映射关系（这一步最关键，全部设计都由它派生）：

| 需求词 | 落成的设计 |
|--------|-----------|
| "无所不用其极" | 六幕六种完全不同的视觉语言（棱镜/CRT/报纸/粉笔树/雪山/宇宙），不重复用同一招 |
| "适配不同时期不同BGM不同剪辑风格" | 每幕独立 BPM（60→120→128→72→92→60）+ 独立配器 + 独立剪辑语法 |
| "拉片感" | 2.35:1 遮幅、胶片颗粒、门架抖动、推镜、闪白过场、虹膜收光 |
| "深度节奏感" | **鼓点网格 = 剪辑网格**：砸卡、砸字的时间戳与音频鼓点共享同一常量 |
| "宁可30s高密度" | 定 56s、1680 帧，无过渡赘肉，每幕只做一件事做到极致 |
| "完整起源到未来眺望" | 时间线必须核实到当下：2023.3 创立 → 2026.7 K3 → AGI 眺望 |

情感/响度曲线（这是成片骨架，先于一切代码）：

```
静(序) → 机械律动(终端) → 密集击打(号外) → 沉思留白(树) → 史诗重锤(K2) → 辽阔收束(宇宙)
quiet → groove → punch → sparse → epic → vast
```

注意不是一路走高——第 3→4 幕故意从满场报纸切到近乎全黑的沉思树，用"落差"制造节奏。高潮放在 31.5–43.5s 的 K2/K3，占全片 21%，是唯一的双幕结构。

两个贯穿线索（让六种风格不散架）：
- **视觉母题**：同一轮月亮。序章光谱收拢成月 → 结尾环月暗面电路星座，首尾闭环。
- **听觉母题**：同一条五声音阶主题动机 E4-G4-A4-B4-D5，每幕换一种配器出现（玻璃铃→方波琶音→锯齿主音→毛毡钢琴→铜管齐奏→铃音再现）。

### 3. 节奏与音画技巧

- **卡点同步**：act2 卡片砸落网格 = 音频太鼓时间戳 = 同一常量 `0.9375s`（128bpm 半小节）。act4 同理 `slams=[3.3,4.1,4.9,5.4]` 视觉砸字与音频 taiko+铜管共用一张时间表。**同步不是对出来的，是同一个数写两遍**。
- **砸入反馈三件套**：`shake`（整数像素偏移）+ `chroma`（R/B 通道错位 ±5px）+ `flash`（叠加色帧闪）——每次砸卡/砸字给 0.2s 的冲击层，是"重"感的来源。
- **速度曲线**：`eo_back(s=2.2)`（回弹过冲缓动）做砸卡入场；`eio`（缓入出）做推镜；`ei` 做离场加速——不同运动用不同缓动签名。
- **转场手法**：硬切为主（风格幕间），闪白/白热过场用在强度顶点（K2 段内），虹膜收光只给结尾——技巧稀缺才有效。
- **声音设计先于编曲**：先写鼓组/riser/sub_pulse 物理建模基元（kick=指数扫频正弦、taiko=80→45Hz+噪声），再编曲；每幕尾部放 `riser()` 白噪声上升，把听觉能量推到切点。
- **心跳母题**：sub_pulse 低音脉动在序章开头（0.7s起）和结尾（53.4s起）各出现一次——声音层面的首尾呼应。

## 二、具体的创作方式

### 1. 技术栈与完整工作流

```
事实核查(web_search) → 分幕表+时间轴(纸面) → kit.py 引擎 → scenes.py 逐幕
→ probe 帧接触印样审片 → score.py 配乐 → RMS包络验音 → film_par.py 并行渲染
→ ffmpeg concat+mux → 抽帧复查 → 降码率交付
```

- **Python 3.10 / numpy 2.2.6**：一切像素运算，float32 (H,W,3) 像素场
- **Pillow 12.3**：CJK 文字精灵、分形树静态层、报纸卡片、高斯模糊、旋转/缩放合成
- **ffmpeg 4.4.2**：rawvideo→x264 编码、concat、mux
- **multiprocessing(fork)**：8 进程切片并行渲染
- **Noto Sans/Serif CJK**（系统字体，SC 字形在 ttc index=2）
- **web_search**：发布日期/参数/跑分全部先核实再写进字幕

### 2. 项目结构与关键代码

```
kimi_film/
├── kit.py       # 渲染引擎：缓动/文字精灵/辉光/颗粒/遮幅/粒子/后处理 ~300行
├── scenes.py    # 六幕渲染函数 + SCENES 时间表 ~600行
├── score.py     # 合成器基元 + 分幕编曲 ~250行
├── film_par.py  # 8进程并行渲染 + concat + mux ~60行
└── film.py      # 单进程渲染版 ~40行
```

核心抽象——**整片是一个纯函数**：


### 3. 每种视觉风格的代码实现

- **Act0 棱镜**：`poly_mask` 三角 + `beam()` 白光入射 + 6 条谱线 fan-out；收拢期每条线两端点都 `lerp` 向月心 `MOON_X,MOON_Y`，光束长度 `L*(1-q)` 收缩；月亮 `add_disc`+terminator 光照函数+maria 高斯斑。
- **Act1 CRT**：48 条随机字符串行预渲染精灵，按列×深度滚动；`scanlines(img,3,0.16)` 扫描线；尾部 `np.roll` 水平切片做 tape-glitch；计数器直接 `text_center` 大字号。
- **Act2 号外**：PIL 预渲染 8 张卡片（纸底+`np.normal` 纸纹+边框+红印章+半调点阵）；当前卡 `eo_back` 缩放砸入，旧卡缩小叠成背景堆；`sin·sin` 半调叠加层。
- **Act3 思维树**：递归分形生成 `(x0,y0,x1,y1,level)` 线段表，每层渲成一张 PIL RGBA 静态层；逐层 alpha 淡入模拟生长；尾段 `ImageChops.offset` 把高层整体上移成星座；尖端节点 `add_dots` 呼吸闪烁；数学符号精灵漂浮。
- **Act4 雪山/山门**：种子化山脊折线 `poly_mask` 剪影 + 黎明背光 `add_glow` + `np.interp` 山脊轮廓金光 + 双碑分离（遮罩矩形+内侧金色 rim）；石碑数据卡 PIL 滑入。
- **Act5 环月**：`add_disc` 月盘 + `term_x` 明暗界线函数扫掠 + 预生成星座（月面暗区节点+最近邻边）`add_dots/add_lines` + 双层视差星场（不同漂移速度）+ 地球 `add_glow/add_disc` + 结尾圆形遮罩虹膜收光。

### 4. 音频处理

- **合成器基元**（score.py，全部 numpy 逐样本）：`osc(sine/tri/sqr/saw/noise)`、`adsr(n,a,d,s,r,sl)`、`bell`（基频+2.76/5.40非谐泛音+指数衰减=玻璃感）、`felt`（正弦+2/3次谐波+快攻击长衰减=毛毡钢琴）、`pad`（tri+detune saw 叠层）、`kick`（140→48Hz 扫频）、`taiko`（108→42Hz+噪声）、`hat`（噪声差分近似高通）、`snare`、`riser`、`sub_pulse`、`click`。
- **混音**：`place()` 等功率声像 `cos/sin(π(pan+1)/4)` 写入立体声总线 → `tanh` 软限幅 → 峰值归一化×0.94 → 0.25s 淡入 / 1.6s 淡出 → int16 WAV（48kHz 立体声）。
- **卡点**：鼓点时间戳与视觉事件共用常量（act2 `0.9375s`、act4 `slams[]`）；act1 数字翻转到 200万 的瞬间配 `riser+sub_pulse`。
- **转场音**：每幕尾 0.5–1.0s 白噪声 `riser` 推到切点；幕间无交叉淡化，硬切配硬切。

### 5. 渲染与导出参数

```bash
# 分块渲染（每进程一条 rawvideo 管道）
ffmpeg -y -f rawvideo -pix_fmt rgb24 -s 1920x1080 -r 30 -i - \
  -c:v libx264 -preset medium -crf 17 -pix_fmt yuv420p chunk_XX.mp4

# 无损拼接（要求各段编码参数完全一致）
ffmpeg -y -f concat -safe 0 -i concat.txt -c copy video_silent.mp4

# 混流（WAV→AAC192k，moov 前置）
ffmpeg -y -i video_silent.mp4 -i score.wav -c:v copy -c:a aac -b:a 192k \
  -shortest -movflags +faststart kimi_film.mp4          # 产出 384MB（颗粒顶爆码率）

# 交付版：同参数降 crf23 + preset slow + AAC160k → 83MB
ffmpeg -y -i kimi_film.mp4 -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p \
  -c:a aac -b:a 160k -movflags +faststart kimi_film_1080p.mp4
```

### 6. 时间分配与提速点

- 事实核查 ~5%（web_search ×3，30 分钟含阅读）
- kit.py 引擎 ~15%；scenes.py 六幕 ~35%；score.py ~15%；debug+视觉打磨 ~25%；渲染+导出 ~5%
- **最耗时：视觉打磨与 bug 修复**（约一半时间）——probe 接触印样审片是最划算的迭代手段，别急着全渲
- 提速：8 进程切片把 ~22min 串行渲染压到 **199s**；星场/粒子画局部补丁（19s/帧→1.4s/帧）；文本精灵缓存杜绝每帧重排字体

## 三、注意事项与踩过的坑

### 1. 开工前逐项检查清单

- [ ] CJK 字体可用且指定 ttc index（NotoSansCJK 的 SC 在 index=2，默认 index=0 是 JP 字形）
- [ ] ffmpeg 版本支持 `concat` + `rawvideo` 管道（4.x 即可）
- [ ] 定死：分辨率/帧率/总时长/遮幅比——它们是下游一切常量的根
- [ ] 字幕中的日期/数字/跑分全部核实过来源
- [ ] 每幕一个 BPM 常量，视觉事件网格与音频网格**从同一个常量派生**
- [ ] 输出目录存在（`out/`），score.wav 先渲还是先出帧顺序明确
- [ ] 情感曲线+视觉母题+听觉母题在动笔前定稿

### 2. 制作中逐项检查清单

- [ ] 每幕先出 probe 接触印样（15 张关键帧拼 sheet）审构图节奏，再谈细节
- [ ] 音频写完先跑逐秒 RMS/peak 包络表，查死区、查爆音
- [ ] 暗色剪影类元素必须配背光/边缘光，否则在暗背景上消失
- [ ] 每次"砸"类动效配齐 shake+chroma+flash 三件套才有重量感
- [ ] 每幕色板收敛在 3–4 个主色内，避免风格内自我打架
- [ ] 惰性缓存（精灵/静态层）在并行 fork 下每进程重建一次，属预期

### 3. 导出前逐项检查清单

- [ ] 片头片尾各抽 1 帧、每个切点 ±1 帧复查
- [ ] `-shortest` 对齐音视频时长（本片都是 56.000s）
- [ ] 音频峰值归一化、首尾淡入淡出存在
- [ ] concat 段间无花屏（要求各段同 codec/同参数/同 fps/同分辨率）

### 4. 交付前逐项检查清单

- [ ] 体积 < ~100MB（颗粒画面码率高，提前按 crf 估档）
- [ ] `-movflags +faststart`（moov 前置，网页/聊天里可边下边播）
- [ ] 最终文件抽帧复查编码伪影，而不只是看渲染帧
- [ ] 附源码包 + README（分幕表/复现命令/依赖列表）

### 5. 实际踩过的坑（现象→根因→解法→预防）

1. **渲染慢到 19s/帧** — `draw_stars` 对每颗星做全帧 `exp`，340 星×全帧。改为小补丁局部绘制（半径 `4s` 的包围盒）→ 1.4s/帧。预防：**粒子/星点永远画局部，复杂度按"星数×补丁"算，不按全帧算**。
2. **PIL resize 报 "box can't exceed original image size"** — `push_in` 推镜裁切框以 `cy=H*0.55` 为中心时超出底边。根因：crop box 未钳制在图内。解法：`cx,cy` 钳到 `[cw/2, W-cw/2]`、`[ch/2, H-ch/2]`。预防：所有裁切框先 clamp。
3. **帧数组变 (1,1,3) float32 崩溃** — `Image.fromarray` 报 `Cannot handle (1,1,3) <f4`。根因：`push_in` 总是返回 float32，而它包在 `finish()`(输出 uint8) 外面时调用方期望 u8；探测脚本从数组上 fromarray 才爆出来。解法：`push_in` 保持输入 dtype。预防：**管线每个函数签名约定固定 dtype**，场景函数统一返回 `uint8 (H,W,3)`。
4. **`pkill -f` 把自己 shell 杀了（exit -1）** — 命令行里含 `film_par` 字样，`-f` 全命令行匹配命中自身。解法：改用 `setsid nohup` 起后台进程。预防：**pkill 模式绝不能出现在自己命令行里**，要杀就按 PID 杀。
5. **配乐 52s 处 1 秒死区** — `pad()` 的 ADSR 没传 sustain level（`sl=0`），和弦尾部衰减到零再接下一和弦。解法：`sl=0.6`。预防：**编曲先跑逐秒 RMS 包络表，空洞一眼可见**。
6. **鼓点与卡片网格漂移** — 音频 taiko 写在 `15.5+i*0.94`，视觉卡片砸在 `15.0+i*1.0`，第八张偏 0.5s。根因：网格各写各的常量。解法：两边统一 `0.9375s`（128bpm 半小节）。预防：**同步网格只许一处定义，音视频两端引用**。
7. **act4 雪山剪影几乎看不见** — 岩色 (22,24,30) 压在 (5,6,10) 背景上。解法：山顶黎明背光 `add_glow` + 雪盖 + `np.interp` 山脊轮廓金光。预防：**剪影 = 轮廓光 + 背光**，不是"画黑一点"。
8. **act4 石碑像悬空黑块** — 碑体是纯黑矩形浮在空气里。解法：配金色内侧 rim + `ga` 淡入 + 落到山脊线上。预防：暗色实体必须给边缘光和落点参照物。
9. **胶片颗粒把码率顶爆** — crf17 下 56s 出 384MB。根因：逐帧独立噪声对编码器是高频不可预测信号。解法：交付版降 crf23+preset slow → 83MB。预防：**颗粒是码率成本**，交付前先按 crf 档估算体积。
10. **文字/图层缓存坑** — 分形树每层静态层只渲一次，否则 127 段线段逐帧重绘=灾难。预防：**一切静态元素进预渲染层**，帧循环只做"合成"不做"重建"。

## 四、可复用的模板

### A. 代码视频制作流程模板

```
0. 需求拆解：关键词 → 情感曲线(响度曲线) → 分幕表(时间段+视觉语言+BPM+配器)
1. 事实核查：所有字幕数字/日期先溯源，落成分幕表
2. 定常量：W,H,FPS,遮幅比,各幕BPM,音画共享的网格常量
3. 引擎层：缓动/文字精灵/辉光/颗粒/遮幅/后处理 (kit.py)
4. 逐幕实现：场景纯函数 render(t_local)，惰性缓存静态层

8. 并行渲染：N进程切片→分段mp4→concat -c copy→mux音频
9. 抽帧复查（切点±1、片头尾）→ 降码率交付版（crf23,faststart）
10. 交付物：成片mp4 + 源码zip + README(分幕表/复现命令/依赖)
```
