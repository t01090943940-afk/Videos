# STORYBOARD · AI-CODING SUPERVIDEOS 总片 V2（120s @150BPM · 4K120）

坐标系：一切时间以「拍」为单位。150 BPM → 1 拍 = 0.4s = 48 帧@120fps = 24 帧@60fps。
任何目标帧率都整数对齐，零漂移。所有镜头/文字/音效共用 `src/edl.mjs` —— 画面切在哪一拍，鼓就落在哪一拍。

> 没有 AE，没有 PR，没有剪辑软件。每一帧，都是时间的函数。

> 28 部×半拍马拉松闪回（一部都不能少）→

> `render(t)` 回车：本片也是 render(t) →「下一部，由你来写。」→ CRT 关机。

## 画面系统（V2 升级）

- **母题**：`frame = render(t)` —— 开场飞成 HUD，解剖段左栏逐行点亮真实源码证明它，尾声自指执行。
- **切片爆发式排版**：「通通开源」每字由上/中/下三条切片组成，砸屏瞬间横向撕开再合拢。
- **定格卡语法**：巨墙 28 格在骤停拍齐换照片海报 + 白边 + 快门音 —— 全片唯一一次最大定格。
- **机械 foley**：打字机当踩镲、boot 蜂鸣+硬盘寻道、铅笔制图沙沙、调制解调器握手当"连接"stinger、CRT 断电哨声收尾 —— 全部是电子机械的呼吸声，没有一件"乐器"。
- **抽帧顿挫**：ERA02 窗口入场运动量化成一拍 4 步 —— 用"低帧率"当叙事信号，暗示逐像素渲染的时代。
- **4K120 管线**：FX 画布后备 3840×2160，deviceScaleFactor 2 输出，全部矢量化绘制——4K 不是拉伸出来的。
- **真空/静默稀缺**：全片只有三处全黑真空（冷开场进正片 / DROP 前半拍 / 骤停前）+ 一次磁带骤停 + 一次 CRT 断电 —— 高峰靠"减法"成立。

## 音频（score.py · numpy 逐样本合成 · 与画面共用 EDL）

- 150 BPM 鼓点网格 == 剪辑网格；Dm–B♭–F–C 进行；动机 D4–F4–A4–D5 按段落移调（马拉松段升至 +10）。
- 解剖段能量 0.55：只有 kick+sub+tick 的机房律动，没有旋律 —— "机器在干活"。
- b148 28 格定格 = 一次快门连发；b150 磁带骤停；马拉松每整拍一击；闪传卡modem握手；尾声 CRT 断电。

## 文件结构

- `src/edl.mjs` —— **唯一真相源**（300 拍节拍图 / 76 镜头 / GRID/WALL/TUNNEL/MARATHON / 全部文字 / 180 个音效 cue）
- `src/catalog.mjs` —— 28 部作品元数据 + 真实统计 + 闪传链接
- `src/code-lines.mjs` —— 代码墙用的真实源码行（可在源码包 Ctrl+F 查到）
- `src/runtime.js` —— `render(t)` 纯函数引擎（16 个场景函数 + 事件表 + 双 FX 画布）
- `src/style.css` —— 视觉系统静态终态
- `tools/build.mjs` —— 生成 index.html（111 个静态 `<video>`）+ build/cues.json
- `tools/prep_media.mjs` —— ffmpeg 切代理/海报（`--force` 全量重建）
- `tools/qa_probe.mjs` —— Playwright 时刻截图 + 错误捕获（**单位是秒**）
- `tools/dbg_probe.mjs` —— 单时刻 DOM/样式调试
- `audio/score.py` —— 配乐合成器（121s）
