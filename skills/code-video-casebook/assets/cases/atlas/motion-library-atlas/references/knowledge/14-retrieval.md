# 渐进式披露：一次只读够用的知识

这份 Skill 的目的首先是发现能力，而不是强迫 AI 采用固定制作方法。保持索引紧凑，具体知识在需要时读取。

## 阅读顺序

先识别用户想看到的效果。读分类摘要和关键词。筛选两三个资源，读取词条中的能力、边界与组合候选。只有决定实现路线后，才深入对应官方文档、既有 Skill 与案例。

## 搜索工具

Skill 包中提供只读的 Python 搜索脚本。它搜索名称、别名、用途和能力，不执行外部命令，不联网，不收集用户数据。无代码执行环境时，直接读分类和库索引。

```bash
python scripts/search_atlas.py "纸张 拼贴"
python scripts/search_atlas.py "collision 3D" --limit 5
python scripts/search_atlas.py "pretext" --json
```

脚本返回应读取的相对路径和证据状态，不把所有正文一次性打印进上下文。相近名字可能是别名、插件或分支，需核对 canonical ID。

## 输出约束

说明资源能提供什么高级能力，以及它不能替你决定什么。把官方事实、原创设计建议和实际测试分开。不要把未运行的例子称为可直接生产。用户已选择工具时，先尊重该选择，再指出可补充的能力。
