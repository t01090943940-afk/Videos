# 组合库之前，先检查接口边界

一个库的自由度不意味着它可以毫无成本地与另一个库组合。词典里的组合关系是候选，不是兼容性保证。

## 六个检查点

输入：接受 DOM、SVG、Canvas、纹理、3D 场景还是数值？输出是否正好能被下一个工具使用？

时间：能否 seek；需要复位、录制事件还是缓存？

坐标：viewBox、像素、设备像素比、米制单位和摄像机空间如何转换？

资源：字体、图片、模型、视频是否已加载，跨域是否允许捕获？

颜色：透明度是否预乘，色彩空间和 tone mapping 是否重复处理？

工程：版本、依赖、包体积、许可证、GPU 内存和生命周期是否冲突？

## 优先复用不同能力，而非叠加相同能力

一个文字测量工具加一个动画时间线，可能比同时引入三套补间库更有效。一个 3D 场景加合法资产和相机约束，可能比重写渲染器更有价值。

组合验证先做最小样例：载入、暂停、跳转、截图、清理，再增加创意。不要把集成失败直接当作模型创作天花板。
