# 虚拟摄影棚：先有可信的空间

目标是复用布景、人物和摄影条件，不是每次生成一套不相干的三维场景。场景资源与镜头表演分开保存即可，不必先设计行业统一语言。

## 最值得固定的基础

尺寸单位、坐标朝向、地面高度、对象命名、角色身高、资产路径、相机预设和主光方向。布景外围同样要合理，避免一转镜头就暴露空白或模型背面。

先用少量资产拍建立镜头、中景与关键接触特写。每个镜头都要有一个要看的对象。推拉摇移不是越多越好；摄影机运动应改变观众获得的信息。

## 防穿模的有效描述

不要只写“禁止穿模”。说明哪个对象与哪个对象接触，接触时刻，允许间隙，碰撞体类型，关节范围，以及是否需要人工约束。角色拿物体时，物体跟随手部和手指包覆是不同问题。

## 资产不是越写实越好

统一低多边形、黏土或微缩风格可能比混用多个写实资产更连贯。引入 HDRI、材质与模型后，先校验尺寸和光照方向。素材授权独立保存。

[Three 示例](https://threejs.org/examples/)、[Blender Python](https://docs.blender.org/api/current/index.html)、[Poly Haven 条款](https://polyhaven.com/license) 是不同环节的入口，不应期待单一库替代全部工种。
