# 从拉片反查组件

不要把“高级感”当作可执行规格。选择具体镜头，描述其形状、层级、运动、材质、声音与切换关系，然后才查工具。

## 一张拉片记录

参考来源与作者；片段时间；镜头要表达的意义；主次焦点；元素层级；进入和退出；关键形变或遮罩；摄影机行为；声音落点；可能实现路线；未知项。观看印象与技术推测分开记录。

例如“纸片撕开后出现地图”可能涉及不规则蒙版、纸张纹理、层间视差、路线描边与镜头推进。它未必需要一个叫 Vox 的专用库。也不能仅凭成片断言作者用了某个软件。

## 案例证据规则

官方 gallery 是案例导航，不意味着其中每件作品都使用同一套工具，也不意味着我们已经逐作审美鉴定。需要保存精确作品链接、作者、时间和实际观察记录，才能称为作品级研究。

当前 222 条“实验方向”是原创设计建议，不是从外部找到的 222 个惊艳作品。28 个本地展示与其实现来源另行标明。后续作品考古可以替换或补充这些建议，不必改工作站结构。
