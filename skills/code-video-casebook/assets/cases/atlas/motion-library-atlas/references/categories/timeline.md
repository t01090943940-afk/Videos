# 时间与编排

控制一个动作，也控制动作之间的关系。

## 先辨别这类能力

把入场、强调、停留与退出分开；静止可以是有意阅读，不等于故障。

## 成片时间与导出

暂停内部自动播放，显式设置当前时间；必要时预采样。DOM/SVG 截图或 Canvas 帧 → 编码。

## 反平庸提醒

缓动要符合物体与叙事功能，不是所有对象都弹簧。

## 资源索引

- [GSAP](../libraries/gsap/README.md)：把对象属性、顺序与缓动放进可控制的时间线。
- [Anime.js](../libraries/anime/README.md)：面向 JS 对象、DOM 与 SVG 的动画编排工具。
- [Motion](../libraries/motion/README.md)：提供 React 与 JavaScript 的动画、布局和手势能力。
- [React Spring](../libraries/react-spring/README.md)：用弹簧模型表达 React 组件属性的动态变化。
- [Tween.js](../libraries/tweenjs/README.md)：轻量数值补间工具，可对普通 JS 对象施加时间变化。
- [Theatre.js](../libraries/theatre/README.md)：用可视化序列编辑器调节代码场景中的属性。
- [Web Animations API](../libraries/waapi/README.md)：浏览器原生动画控制接口，可控制播放状态与当前时间。
- [CSS Animations](../libraries/css-animation/README.md)：通过关键帧和可动画 CSS 属性描述视觉变化。
- [mo.js](../libraries/mojs/README.md)：提供形状、爆发和时间线等偏图形化的运动原语。
- [GSAP Flip](../libraries/flip/README.md)：在两种布局状态之间建立视觉连续的变换。
- [GSAP MotionPath](../libraries/motionpath/README.md)：让对象沿路径移动并根据路径方向旋转。
- [GSAP ScrollTrigger](../libraries/scrolltrigger/README.md)：将滚动位置关联到动画进度、固定和触发。
