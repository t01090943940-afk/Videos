# 生成艺术

噪声、粒子、线条与规则生成的视觉。

## 先辨别这类能力

选择一到两个主参数；先保证构图再提高粒子数量。

## 成片时间与导出

固定随机种子；累计模拟预计算或从零复算。Canvas/WebGL 帧捕获。

## 反平庸提醒

噪声、粒子和故障风不应没有语义地常驻画面。

## 资源索引

- [p5.js](../libraries/p5/README.md)：提供绘图、噪声、交互和 WebGL 的创意编程入口。
- [canvas-sketch](../libraries/canvas-sketch/README.md)：为生成艺术草图提供尺寸、动画和导出组织。
- [regl](../libraries/regl/README.md)：把 WebGL 绘制状态封装成声明式命令。
- [OGL](../libraries/ogl/README.md)：相对轻量的 WebGL 工具层，提供几何、着色器和场景辅助。
- [tsParticles](../libraries/tsparticles/README.md)：用配置组织粒子发射、交互和预设效果。
