# 角色与动画资产

复用设计好的矢量与骨骼动画。

## 先辨别这类能力

动画资产、字体、贴图和 runtime 分别核对版本及授权。

## 成片时间与导出

暂停自动播放；固定帧或重放状态输入事件。运行时捕获 → 合成。

## 反平庸提醒

引入现成资产不代表可以声称 AI 从零制作了角色动作。

## 资源索引

- [Lottie Web](../libraries/lottie/README.md)：播放由支持工具导出的矢量动画数据。
- [dotLottie Web](../libraries/dotlottie/README.md)：面向 dotLottie 动画包的 Web 播放运行时。
- [Rive](../libraries/rive/README.md)：以动画和状态机连接设计工具与实时交互。
- [Spine Runtimes](../libraries/spine/README.md)：播放 Spine 制作的二维骨骼动画。
