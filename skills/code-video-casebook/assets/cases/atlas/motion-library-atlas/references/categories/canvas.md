# 二维场景

精灵、图片、蒙版和大量平面图层。

## 先辨别这类能力

分辨率、pixel ratio、滤镜区与资源就绪必须固定。

## 成片时间与导出

禁用 ticker 累加或从固定初态重建每个时间。Canvas 图像序列 / WebCodecs + 封装器。

## 反平庸提醒

大量图层运动应有主次，不能每一层同时争抢注意。

## 资源索引

- [PixiJS](../libraries/pixi/README.md)：以 GPU 加速的场景图管理精灵、容器和二维效果。
- [Konva](../libraries/konva/README.md)：用 Stage、Layer 和形状对象组织 Canvas，兼顾编辑交互。
- [Fabric.js](../libraries/fabric/README.md)：对象化 Canvas，适合图像、矢量和编辑器型应用。
- [Canvas 2D](../libraries/canvas2d/README.md)：浏览器原生即时绘图表面，可直接从时间计算每一帧。
- [Skia Canvas](../libraries/skia-canvas/README.md)：在服务端使用类似 Canvas 的接口进行高质量二维绘制。
