# 文字与排版

让文字可读、有层级，并在时间中表达。

## 先辨别这类能力

用实际字体检查最长文案；中文字数与英文单词不能用同一测量假设。

## 成片时间与导出

先固定字体和排版，再给字符或语义分组赋时间。SVG/DOM 捕获或轮廓绘制 → 帧序列。

## 反平庸提醒

整段文字持续抖动、飞散和扰乱，会损害理解。

## 资源索引

- [GSAP SplitText](../libraries/splittext/README.md)：把文字拆成字、词或行，以便分别动画。
- [GSAP ScrambleText](../libraries/scrambletext/README.md)：用字符替换制造文字解码与扰动效果。
- [Pretext](../libraries/pretext/README.md)：快速测量和布局文本，为自定义排版提供几何信息。
- [OpenType.js](../libraries/opentype/README.md)：读取字体轮廓和字形信息，为路径级文字效果提供数据。
- [Troika 3D Text](../libraries/troika/README.md)：基于 SDF 的 Three.js 文字渲染，适合三维场景中的清晰标签。
- [KaTeX](../libraries/katex/README.md)：将数学表达式排版为浏览器可呈现的公式。
