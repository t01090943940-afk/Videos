# 数据与图解

把信息关系变成可看懂的图形关系。

## 先辨别这类能力

标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 成片时间与导出

固定数据与对象身份，显式插值几何或视图信号。SVG/Canvas 捕获 → 视频合成。

## 反平庸提醒

高级图形不是把所有数字同时翻滚。

## 资源索引

- [D3.js](../libraries/d3/README.md)：将数据映射到尺度、形状、布局和 DOM。
- [Apache ECharts](../libraries/echarts/README.md)：丰富图表与数据更新动效，含跨类型通用过渡。
- [Chart.js](../libraries/chartjs/README.md)：以 Canvas 绘制常见统计图表，并支持更新动画。
- [Vega](../libraries/vega/README.md)：用声明式描述数据、标记、尺度和交互。
- [Vega-Lite](../libraries/vega-lite/README.md)：以精简配置表达统计图和组合视图。
- [Observable Plot](../libraries/observable-plot/README.md)：用 marks 和 transforms 快速构造数据图形。
- [visx](../libraries/visx/README.md)：将数据可视化基础能力与 React 组合。
- [React Flow](../libraries/reactflow/README.md)：在 React 中组织节点、边和交互画布。
- [Mermaid](../libraries/mermaid/README.md)：把文本描述转换为流程、序列与其他图解。
