# 前端视觉与调参

把优秀交互组件转化为受控的镜头素材。

## 先辨别这类能力

交互示例改编要核对尺寸、依赖、字体、授权与降级。

## 成片时间与导出

将鼠标、滚动与 hover 记录或参数化为可重放轨迹。页面捕获 → 剪辑与标注。

## 反平庸提醒

不能把登陆页的慢滚动直接当成紧凑视频。

## 资源索引

- [React Bits](../libraries/reactbits/README.md)：收集 React 视觉、背景和文字等交互组件。
- [Magic UI](../libraries/magicui/README.md)：React、TypeScript 和动画技术构建的界面组件集合。
- [Aceternity UI](../libraries/aceternity/README.md)：提供视觉表现较强的 React 界面与动画组件。
- [Animista](../libraries/animista/README.md)：可探索和生成 CSS 动画预设。
- [Embla Carousel](../libraries/embla/README.md)：为轮播与滑动布局提供低层能力。
- [lil-gui](../libraries/lil-gui/README.md)：为 JavaScript 对象快速建立参数控制面板。
- [Leva](../libraries/leva/README.md)：为 React 应用的参数实验提供控制面板。
