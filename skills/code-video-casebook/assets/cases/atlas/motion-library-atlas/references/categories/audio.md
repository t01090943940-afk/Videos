# 声音与节拍

合成、播放、分析与声画同步。

## 先辨别这类能力

分开 BGM、旁白、音效与静默；控制响度、削波和版权。

## 成片时间与导出

最终音轨用离线采样时间；实时播放只作预览。WAV/音频数据 → 与视频混合编码。

## 反平庸提醒

音乐合成与 AI 作曲不是一回事，节拍不能覆盖旁白可理解性。

## 资源索引

- [Tone.js](../libraries/tone/README.md)：在 Web Audio 之上提供合成器、效果和音乐时间调度。
- [Web Audio API](../libraries/web-audio/README.md)：音频节点图、合成、分析和离线渲染的原生接口。
- [Howler.js](../libraries/howler/README.md)：简化音频播放、音频精灵和跨浏览器使用。
- [WaveSurfer.js](../libraries/wavesurfer/README.md)：展示可交互波形并辅助音频区域与播放操作。
- [Meyda](../libraries/meyda/README.md)：提取音频特征，用于声音分析和可视化映射。
- [Tone.js MIDI](../libraries/midi/README.md)：读取和组织 MIDI 音符、轨道和时间信息。
