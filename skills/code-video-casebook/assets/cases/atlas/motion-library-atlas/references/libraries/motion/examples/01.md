# Motion · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

将产品界面状态切换做成具有方向感的连续镜头。

## 需要调用的能力

animate, layout, 手势与弹簧, SVG 动画。

## 先检查什么

交互触发器不是视频脚本；部分高级组件与 AI Kit 功能有独立许可或付费条件。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

把交互状态记录成可重放事件；验证动画控制对象能否受统一时钟驱动。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
