# GSAP · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

用 Flip 让卡片网格变成全屏主视觉并保持对象连续性。

## 需要调用的能力

嵌套 timeline, stagger, seek, 插件生态。

## 先检查什么

时间线能力不包含自动设计；依赖布局的插件需要稳定 DOM 和字体。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

暂停主时间线后显式定位时间；保留 labels；清理作用域与重复实例。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
