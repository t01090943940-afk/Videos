# GSAP ScrambleText

> 类型：插件 · 分类：文字与排版 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

用字符替换制造文字解码与扰动效果。

- 文本扰动
- 字符集控制
- 揭示进度

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让数据编号先解码，再切为对应图表。
- [实验方向 02](./examples/02.md)：用短暂故障字体标记信号异常，而非通篇故障风。

## 能力边界

字符噪音不适合持续阅读；不要把字幕正文全程打乱。

## 使用建议（本词典编辑性判断）

- 只作用于短标题或编号；为最终文本留足稳定阅读时间。
- 用实际字体检查最长文案；中文字数与英文单词不能用同一测量假设。

## 时间线与输出

先固定字体和排版，再给字符或语义分组赋时间。

SVG/DOM 捕获或轮廓绘制 → 帧序列。

## 组合候选

[splittext](../splittext/README.md), [pretext](../pretext/README.md), [gsap](../gsap/README.md), [svg](../svg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 整段文字持续抖动、飞散和扰乱，会损害理解。
