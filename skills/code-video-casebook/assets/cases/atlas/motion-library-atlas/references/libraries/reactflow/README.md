# React Flow

> 类型：节点界面库 · 分类：数据与图解 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

在 React 中组织节点、边和交互画布。

- 节点
- 边
- 视口
- 自定义组件

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：按因果顺序点亮一个机制网络。
- [实验方向 02](./examples/02.md)：从整体系统图推进到关键子流程。

## 能力边界

面向编辑和交互；布局、镜头和成片时间仍需另外设计。

## 使用建议（本词典编辑性判断）

- 为节点稳定命名；先保存布局；将交互状态转换为可重放事件。
- 标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 时间线与输出

固定数据与对象身份，显式插值几何或视图信号。

SVG/Canvas 捕获 → 视频合成。

## 组合候选

[d3](../d3/README.md), [svg](../svg/README.md), [remotion](../remotion/README.md), [observable-plot](../observable-plot/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 高级图形不是把所有数字同时翻滚。
