# MapLibre GL JS

> 类型：地图引擎 · 分类：地图与空间数据 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

用 WebGL 显示矢量地图并控制相机与图层。

- 地图图层
- 相机飞行
- 地理数据
- 样式

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让路线推进与旁白同步，镜头只跟随当前关键地点。
- [实验方向 02](./examples/02.md)：以同一尺度对比两片区域，避免视角暗示错误面积。

## 能力边界

地图数据、瓦片和字形服务各有许可与网络依赖；不是所有内容可离线分发。

## 使用建议（本词典编辑性判断）

- 固定地图样式与数据快照；等待 tiles 就绪；拍摄路径与地图数据分离。
- 核对底图与数据许可；标记示意地图；保留必需署名。

## 时间线与输出

显式路径与地图时钟；等待关键瓦片、字形及地形。

固定视口捕获 → 视频。

## 常见平庸与失败模式

- 持续飞越不能代替地理解释，透视也可能误导面积。

## 进一步辨别

### 地图多了数据许可与加载状态

开源地图引擎不等于所有底图和瓦片都免费。先记录地图样式、瓦片服务、字体与署名要求。跨域资产也会影响截图或离线复用。

避免把很长的 fly-to 当成解释。先确定必须建立的空间关系，再用最少的相机移动说明它。示意路线和真实地理路线应明确标注。

[官方 docs](https://maplibre.org/maplibre-gl-js/docs/) 是实现入口。本地 route 是虚构示意地图，并未使用真实地理数据或 MapLibre。
