# dotLottie Web

> 类型：动画运行时 · 分类：角色与动画资产 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

面向 dotLottie 动画包的 Web 播放运行时。

- 动画包
- 播放控制
- 状态功能
- Web 运行时

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 02](./examples/02.md)：在同一 UI 演示里切换按钮与提示动画。

## 能力边界

不同 runtime 支持功能不同；包内字体和资源也有授权问题。

## 使用建议（本词典编辑性判断）

- 锁定运行时版本；验证帧控制、资源加载和输出一致性。
- 动画资产、字体、贴图和 runtime 分别核对版本及授权。

## 时间线与输出

暂停自动播放；固定帧或重放状态输入事件。

运行时捕获 → 合成。
