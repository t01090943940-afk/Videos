# Chart.js

> 类型：图表库 · 分类：数据与图解 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

以 Canvas 绘制常见统计图表，并支持更新动画。

- 统计图
- 插件
- 动画
- 响应式布局

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：为一组指标做紧凑的对比更新。
- [实验方向 02](./examples/02.md)：将主图与一个放大局部的辅助图同步。

## 能力边界

不专注复杂叙事与任意图形；默认响应式尺寸会干扰视频构图。

## 使用建议（本词典编辑性判断）

- 固定宽高与设备像素比；决定是否关闭内置动画后由外部时间驱动。
- 标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 时间线与输出

固定数据与对象身份，显式插值几何或视图信号。

SVG/Canvas 捕获 → 视频合成。

## 组合候选

[d3](../d3/README.md), [svg](../svg/README.md), [remotion](../remotion/README.md), [observable-plot](../observable-plot/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 高级图形不是把所有数字同时翻滚。
