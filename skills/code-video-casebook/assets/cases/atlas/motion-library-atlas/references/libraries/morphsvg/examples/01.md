# GSAP MorphSVG · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把一个折线标识变成相关机制的轮廓。

## 需要调用的能力

路径变形, 形状转换, 点映射, Canvas 回调。

## 先检查什么

复杂孔洞或语义结构仍需拆路径与中间形态设计；不保证任意两图自动漂亮。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

先调 shapeIndex 和分段映射；抽查半程形态；固定路径数据。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
