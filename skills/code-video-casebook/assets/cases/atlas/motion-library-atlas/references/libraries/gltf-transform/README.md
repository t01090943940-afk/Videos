# glTF Transform

> 类型：资产工具 · 分类：专业工具与资产 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

读取、优化和修改 glTF / GLB 资产。

- 去重
- 量化
- 压缩
- 节点和网格处理

## 能力边界

优化可能影响视觉或扩展兼容；不是建模与动作创作器。

## 使用建议（本词典编辑性判断）

- 优化前后渲染对照；保留原始文件；确认目标 renderer 支持使用的扩展。
- 资产、作品、软件和网站 API 的许可证是不同层；执行第三方脚本前审查。
