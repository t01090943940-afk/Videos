# PixiJS · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

让多层照片拼贴在空间中错落推进。

## 需要调用的能力

sprites, filters, masks, 纹理与粒子。

## 先检查什么

不同 renderer 支持有差异；滤镜和高分辨率纹理会增加显存压力。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

显式更新 ticker 或禁用自动时钟；复用纹理；将高成本滤镜限制到必要区域。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
