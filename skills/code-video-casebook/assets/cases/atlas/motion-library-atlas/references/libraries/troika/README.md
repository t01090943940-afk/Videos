# Troika 3D Text

> 类型：3D 文本库 · 分类：文字与排版 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

基于 SDF 的 Three.js 文字渲染，适合三维场景中的清晰标签。

- SDF 文本
- 自动排版
- 字体解析
- 材质集成

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把产品结构标签置于三维空间并保持阅读层级。
- [实验方向 02](./examples/02.md)：让标题穿过空间而不是平贴屏幕，同时控制遮挡关系。

## 能力边界

不是所有材质与后期都无需适配；字体处理是异步的。

## 使用建议（本词典编辑性判断）

- 等待同步完成再捕获；将文字尺寸与相机距离一起检查。
- 用实际字体检查最长文案；中文字数与英文单词不能用同一测量假设。

## 时间线与输出

先固定字体和排版，再给字符或语义分组赋时间。

SVG/DOM 捕获或轮廓绘制 → 帧序列。

## 组合候选

[splittext](../splittext/README.md), [pretext](../pretext/README.md), [gsap](../gsap/README.md), [svg](../svg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 整段文字持续抖动、飞散和扰乱，会损害理解。
