# Puppeteer

> 类型：自动化工具 · 分类：捕获与导出 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

通过高层 API 控制浏览器，适合捕获与自动测试。

- 浏览器控制
- 截图
- 脚本执行
- 无头运行

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：逐帧捕获一个受控 HTML 合成。
- [实验方向 02](./examples/02.md)：为多个分辨率自动截图，找出字幕溢出。

## 能力边界

浏览器版本与环境影响结果；没有自动理解画面叙事。

## 使用建议（本词典编辑性判断）

- 固定浏览器与 viewport；等待应用 ready；显式调用渲染时间。
- 检查首尾帧、时长、可解码性与音画同步；成功退出不等于质量达标。

## 时间线与输出

明确视频时基与帧序号；录屏与逐帧渲染分开记录。

记录容器、codec、fps、采样率和像素格式。

## 组合候选

[ffmpeg](../ffmpeg/README.md), [playwright](../playwright/README.md), [webcodecs](../webcodecs/README.md), [mediabunny](../mediabunny/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 浏览器实时 60fps 不证明最终视频不掉帧或逐帧确定。

```text
创作输入：主题=[填写]；目标观众=[填写]；时长=[填写]；画幅=[填写]；旁白/素材=[填写]；参考画面=[填写]。

先输出可运行的代表镜头，再渲染检查首帧、动作中间、转场两侧和尾帧。检测文字越界、非意图遮挡、资源缺失与不同步；3D 另检镜头及可见网格穿透。

```
