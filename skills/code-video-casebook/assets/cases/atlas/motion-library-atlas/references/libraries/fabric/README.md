# Fabric.js

> 类型：2D 场景库 · 分类：二维场景 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

对象化 Canvas，适合图像、矢量和编辑器型应用。

- 对象变换
- clipPath
- 滤镜
- 序列化

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把一张设计稿变成逐层构建的可解释动画。
- [实验方向 02](./examples/02.md)：让图像蒙版在多个布局中保持同一对象。

## 能力边界

是图形与编辑基础，不是完整视频时间线；导入 SVG 可能有特性差异。

## 使用建议（本词典编辑性判断）

- 保存对象身份与层级；缓存静态对象；导出时检查跨域资源污染。
- 分辨率、pixel ratio、滤镜区与资源就绪必须固定。

## 时间线与输出

禁用 ticker 累加或从固定初态重建每个时间。

Canvas 图像序列 / WebCodecs + 封装器。

## 组合候选

[pixi](../pixi/README.md), [gsap](../gsap/README.md), [canvas2d](../canvas2d/README.md), [ffmpeg](../ffmpeg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 大量图层运动应有主次，不能每一层同时争抢注意。
