# Leva

> 类型：React 调参库 · 分类：前端视觉与调参 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

为 React 应用的参数实验提供控制面板。

- 参数面板
- 数值
- 颜色
- 分组

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：给生成艺术场景快速比较多种参数组合。
- [实验方向 02](./examples/02.md)：对同一 3D 片场保存几个可重复的拍摄配置。

## 能力边界

不负责渲染；依赖 React 环境，预设与时间线要自己衔接。

## 使用建议（本词典编辑性判断）

- 将参数改变保存为明确配置；不要让调参状态成为隐藏依赖。
- 交互示例改编要核对尺寸、依赖、字体、授权与降级。

## 时间线与输出

将鼠标、滚动与 hover 记录或参数化为可重放轨迹。

页面捕获 → 剪辑与标注。

## 组合候选

[motion](../motion/README.md), [gsap](../gsap/README.md), [playwright](../playwright/README.md), [waapi](../waapi/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 不能把登陆页的慢滚动直接当成紧凑视频。
