# Web Audio API · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

分析一段音频的能量并映射到有限的视觉参数。

## 需要调用的能力

AudioContext, OfflineAudioContext, 频谱, 节点连接。

## 先检查什么

音频时钟与画面时钟不同；设备播放延迟不能直接作为视频同步依据。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

优先离线渲染音轨；记录采样率；避免削波并测试声画对齐。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
