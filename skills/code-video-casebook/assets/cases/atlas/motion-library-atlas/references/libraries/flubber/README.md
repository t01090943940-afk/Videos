# Flubber

> 类型：插值库 · 分类：矢量与手绘 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

为二维轮廓之间的形变生成中间形状。

- SVG path 插值
- 多边形插值
- 分裂合并辅助

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：从人口轮廓变成数据面积，保持信息尺度说明。
- [实验方向 02](./examples/02.md)：把一个品牌符号拆成数个分类图形，最后重新汇聚。

## 能力边界

是尽力的几何插值，不保证复杂孔洞、拓扑或设计语义正确。

## 使用建议（本词典编辑性判断）

- 先规范轮廓；抽查中间形状；对困难形变用分镜切换而非强行连续。
- 核对路径身份、方向、孔洞、viewBox 与中间帧。

## 时间线与输出

形状与笔触先准备，运动由 t 或受控时间线求值。

SVG 渲染或 Canvas 捕获。

## 组合候选

[d3](../d3/README.md), [svg](../svg/README.md), [gsap](../gsap/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 随机手绘每帧重生成会变成闪烁，不是质感。

## 进一步辨别

### 形状对应比变化本身更重要

两个轮廓能插值，不代表观众会理解它们为什么变成彼此。先决定变化要表达分类、数量、因果还是品牌身份，再选择中间形态。

测试形变时至少检查开始、25%、50%、75% 和结束。注意翻转、自交、突然缩小及孔洞丢失。必要时拆成多个路径，或以遮罩切换代替伪装成连续形变。

[Flubber 作者资料](https://github.com/veltman/flubber) 与 [MorphSVG 文档](https://gsap.com/docs/v3/Plugins/MorphSVGPlugin/) 是可比较的两条路线，不应在未测试时直接给谁‘9 分’。
