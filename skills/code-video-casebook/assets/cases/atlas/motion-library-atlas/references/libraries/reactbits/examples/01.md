# React Bits · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把一个背景效果限定为章节转折的 2 秒强调。

## 需要调用的能力

文字效果, 交互背景, UI 动效, React 组件。

## 先检查什么

很多示例依赖实时鼠标、滚动或 GPU；可用源码不等于全部案例可直接成片。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

逐例审查依赖、许可和输入；将交互参数变成显式时间轨迹。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
