# Matter.js

> 类型：2D 物理引擎 · 分类：物理与约束 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

为二维刚体、碰撞与约束提供成熟模型。

- 刚体
- 碰撞
- 约束
- 复合体

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让文字卡片以不同质量落在秤盘上。
- [实验方向 02](./examples/02.md)：用摆和约束解释一个简单的机械因果链。

## 能力边界

二维碰撞不意味着三维场景成立；堆叠稳定性受时间步和参数影响。

## 使用建议（本词典编辑性判断）

- 固定 delta；从同一初始状态开始模拟；将结果缓存到镜头时间线上。
- 验证碰撞体、CCD、关节范围、接触容差；烘焙不代表网格绝不会交叠。

## 时间线与输出

固定 dt 与初始状态，离线模拟并采样；不要把求解器当随机 seek。

物理状态 → 渲染器 → 视频。
