# Meyda

> 类型：分析库 · 分类：声音与节拍 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

提取音频特征，用于声音分析和可视化映射。

- 频谱特征
- 时域特征
- 实时分析
- 离线特征

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：将音色变化映射为纹理，而音量只控制大小。
- [实验方向 02](./examples/02.md)：比较两段声音的特征轨迹，明确不是诊断结论。

## 能力边界

特征值不等于语义节拍；噪声和窗口大小会改变结果。

## 使用建议（本词典编辑性判断）

- 固定窗口、采样率和归一化；平滑参数避免视觉闪烁。
- 分开 BGM、旁白、音效与静默；控制响度、削波和版权。

## 时间线与输出

最终音轨用离线采样时间；实时播放只作预览。

WAV/音频数据 → 与视频混合编码。

## 组合候选

[tone](../tone/README.md), [web-audio](../web-audio/README.md), [midi](../midi/README.md), [ffmpeg](../ffmpeg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 音乐合成与 AI 作曲不是一回事，节拍不能覆盖旁白可理解性。
