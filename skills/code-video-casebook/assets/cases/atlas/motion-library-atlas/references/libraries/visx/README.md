# visx

> 类型：React 组件库 · 分类：数据与图解 · 研究快照：2026-09-24
> 证据：入口索引。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

将数据可视化基础能力与 React 组合。

- scales
- shapes
- axes
- React 组件

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：给品牌片做保持品牌排版的定制图表。
- [实验方向 02](./examples/02.md)：把图表拆为可独立运动的轴、数据和注释。

## 能力边界

偏底层组合，AI 仍需做布局与动画决策；不等于开箱即用导演模板。

## 使用建议（本词典编辑性判断）

- 让 React 帧状态生成图形属性；保留 scale 域避免每帧跳轴。
- 标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 时间线与输出

固定数据与对象身份，显式插值几何或视图信号。

SVG/Canvas 捕获 → 视频合成。

## 组合候选

[d3](../d3/README.md), [svg](../svg/README.md), [remotion](../remotion/README.md), [observable-plot](../observable-plot/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 高级图形不是把所有数字同时翻滚。
