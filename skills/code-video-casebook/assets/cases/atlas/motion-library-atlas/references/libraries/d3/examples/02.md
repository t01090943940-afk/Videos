# D3.js · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

让层级数据先分组再展开，解释结构而非炫技。

## 需要调用的能力

scales, shapes, data join, 布局算法。

## 先检查什么

D3 不是视频渲染器；transition 的真实时间不天然等于视频时间。本地附带案例使用 D3 3.x，不代表现行 API 验证。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

给数据稳定 key；先算布局，再用统一时间插值几何；标明数据是否合成。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
