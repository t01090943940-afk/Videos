# GL Transitions · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

让一道方向明确的位移连接前后两镜的运动。

## 需要调用的能力

texture transition, progress, shader 集合。

## 先检查什么

效果库不等于自动剪辑；授权按单个项目和素材分别检查。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

核对输入长宽比与颜色空间；用进度显式求帧；不要连续堆强特效。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
