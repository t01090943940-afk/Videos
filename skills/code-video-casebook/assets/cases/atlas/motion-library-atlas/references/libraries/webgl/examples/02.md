# WebGL · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

实现一个只有几何与光影的抽象产品片头。

## 需要调用的能力

shader, textures, framebuffer, GPU 绘制。

## 先检查什么

上限高但实现成本高；驱动差异、精度和上下文丢失需处理。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

显式尺寸与时间 uniform；检查 shader 编译日志；同环境验证帧可重复性。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
