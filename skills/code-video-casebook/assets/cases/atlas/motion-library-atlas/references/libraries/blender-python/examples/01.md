# Blender Python API · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

用脚本生成多机位拍摄列表。

## 需要调用的能力

bpy.data, 关键帧, 渲染调用, 场景管理。

## 先检查什么

bpy.ops 依赖上下文；不是普通 Python 环境安装即等同完整 Blender。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

优先明确数据引用；避免无谓选择操作；脚本运行前保存工程副本。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
