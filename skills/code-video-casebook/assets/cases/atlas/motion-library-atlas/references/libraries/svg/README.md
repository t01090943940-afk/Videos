# SVG

> 类型：Web 标准 · 分类：矢量与手绘 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

基于文档结构描述矢量图形、蒙版和滤镜。

- paths
- mask
- clipPath
- filters

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：用负形蒙版从文字切换到场景。
- [实验方向 02](./examples/02.md)：将复杂解释图分层，按论点逐个揭示。

## 能力边界

复杂滤镜性能与浏览器一致性需测试；SVG 不自带完整视频输出。

## 使用建议（本词典编辑性判断）

- 统一 viewBox；对象使用稳定 ID；蒙版单位与 transform 坐标明确。
- 核对路径身份、方向、孔洞、viewBox 与中间帧。

## 时间线与输出

形状与笔触先准备，运动由 t 或受控时间线求值。

SVG 渲染或 Canvas 捕获。

## 组合候选

[gsap](../gsap/README.md), [rough](../rough/README.md), [flubber](../flubber/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 随机手绘每帧重生成会变成闪烁，不是质感。
