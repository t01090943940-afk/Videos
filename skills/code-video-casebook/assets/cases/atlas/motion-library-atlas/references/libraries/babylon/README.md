# Babylon.js

> 类型：3D 引擎 · 分类：三维与摄影 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

较完整的 Web 3D 引擎与工具生态。

- PBR
- 场景
- 动画
- 引擎工具

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 02](./examples/02.md)：用材质、灯光和剖切表达结构层次。

## 能力边界

复杂引擎选项增加配置面；功能支持与 WebGPU 路径需逐项核对。

## 使用建议（本词典编辑性判断）

- 先建立可重复的相机和渲染设置；不要把实时演示帧率当成离线质量指标。
- 分清米制尺寸、坐标朝向、碰撞体和可见网格；检查镜头穿物与近裁剪。

## 时间线与输出

相机、姿态与灯光都受显式 t 驱动；模拟提前烘焙。

WebGL 帧或 DCC 渲染序列 → 合成。

## 组合候选

[three](../three/README.md), [drei](../drei/README.md), [rapier](../rapier/README.md), [blender](../blender/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 推拉摇移应改变理解；不停绕场不等于电影感。
