# Observable Plot

> 类型：绘图库 · 分类：数据与图解 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

用 marks 和 transforms 快速构造数据图形。

- 数据标记
- 分面
- 统计转换
- SVG 图形

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：用一张可读的点图代替大段统计文字。
- [实验方向 02](./examples/02.md)：将分面逐个显露，建立群体间的对照。

## 能力边界

不提供完整视频时间线；动态部分需要控制数据或外部图层。

## 使用建议（本词典编辑性判断）

- 把事实数据与镜头参数分开；以静态图先检验编码是否诚实。
- 标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 时间线与输出

固定数据与对象身份，显式插值几何或视图信号。

SVG/Canvas 捕获 → 视频合成。

## 组合候选

[d3](../d3/README.md), [svg](../svg/README.md), [remotion](../remotion/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 高级图形不是把所有数字同时翻滚。
