# Revideo

> 类型：框架 · 分类：视频框架 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

基于代码的视频制作工具，延续 Motion Canvas 相关思路。

- 代码场景
- 参数化
- 媒体
- 渲染

- 从当前仓库示例开始；锁定依赖；不要与 Motion Canvas 文档混用。
