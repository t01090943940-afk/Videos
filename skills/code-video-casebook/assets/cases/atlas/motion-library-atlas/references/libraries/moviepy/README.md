# MoviePy

> 类型：Python 库 · 分类：视频框架 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

在 Python 中组合视频、图片与声音，适合批量生成和后处理。

- 裁剪拼接
- 合成图层
- 音轨处理
- 函数式视频帧

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把实验结果图片和旁白拼成一组可批量更新的解释视频。
- [实验方向 02](./examples/02.md)：给同一段 Python 动画加章节、结尾和字幕安全区。

## 能力边界

大型逐帧 Python 合成可能较慢；v1 与 v2 的导入与 API 存在差异。

## 使用建议（本词典编辑性判断）

- 锁定版本并缓存昂贵图层；将复杂视觉先渲染成素材再合成。
- 先确定画幅、帧率与音轨；同一镜头不同时间单独检查。

## 时间线与输出

显式帧时间或框架官方渲染时间线。

使用框架输出，或帧序列 → FFmpeg。
