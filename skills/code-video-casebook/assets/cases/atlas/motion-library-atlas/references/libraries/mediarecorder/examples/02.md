# MediaRecorder · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

记录用户调参后的快速视觉预览，并标明不是最终母版。

## 需要调用的能力

MediaStream, 分块录制, 音视频流, 实时捕获。

## 先检查什么

不保证严格逐帧输出；支持格式因浏览器而异，实时负载可导致掉帧。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

检测 MIME 支持；等待 stop 后汇总数据；生产逐帧导出采用独立管线。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
