# Mediabunny

> 类型：媒体库 · 分类：捕获与导出 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

在 JavaScript 中读写和处理媒体文件，面向现代 Web 媒体能力。

- 媒体读写
- 编解码衔接
- 转换
- 多环境 API

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把 Canvas 帧与音轨封装成可播放文件。
- [实验方向 02](./examples/02.md)：让工作站在本地处理短素材而不上传。

## 能力边界

容器与编解码支持取决于库及环境；不负责画面创作。

## 使用建议（本词典编辑性判断）

- 先检测目标编解码器；显式时间戳；检查音视频时基与结束帧。
- 检查首尾帧、时长、可解码性与音画同步；成功退出不等于质量达标。

## 时间线与输出

明确视频时基与帧序号；录屏与逐帧渲染分开记录。

记录容器、codec、fps、采样率和像素格式。

## 组合候选

[ffmpeg](../ffmpeg/README.md), [playwright](../playwright/README.md), [webcodecs](../webcodecs/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 浏览器实时 60fps 不证明最终视频不掉帧或逐帧确定。
