# Poly Haven · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

用匹配日照方向的环境资源建立可信摄影棚。

## 需要调用的能力

HDRI, PBR 纹理, 模型, CC0 资产。

## 先检查什么

资产 CC0 不等于网站文字、示例渲染及 API 可随意抓取；网站及 API 有独立条款。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

使用官方允许的下载方式；保存资产来源；不要擅自镜像站点或把展览作品当自有素材。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
