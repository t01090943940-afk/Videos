# Planck.js

> 类型：2D 物理库 · 分类：物理与约束 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

JavaScript 二维物理引擎，延续 Box2D 的概念模型。

- 碰撞
- 关节
- 刚体
- 测试场景

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：通过滑轮和连杆演示力的传递。
- [实验方向 02](./examples/02.md)：让抽象图形的运动遵守约束而不是随意浮动。

## 能力边界

物理求解不提供艺术指导；随机与输入必须受控。

## 使用建议（本词典编辑性判断）

- 先复用官方示例的世界配置；验证极端帧与接触事件。
- 验证碰撞体、CCD、关节范围、接触容差；烘焙不代表网格绝不会交叠。

## 时间线与输出

固定 dt 与初始状态，离线模拟并采样；不要把求解器当随机 seek。

物理状态 → 渲染器 → 视频。

[rapier](../rapier/README.md), [three](../three/README.md), [matter](../matter/README.md), [canvas2d](../canvas2d/README.md)。组合关系仅是研究候选，不代表已验证兼容。
