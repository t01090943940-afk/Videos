# HyperFrames

> 类型：框架 · 分类：视频框架 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

HeyGen 的 HTML 代码视频体系，将网页动画放进可定位的合成时间轴。

- HTML composition
- seekable 时间线
- 多动画运行时
- 检查与渲染工具

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：把纸片拼贴、文字节奏和 3D 产品镜头放进一个合成。
- [实验方向 02](./examples/02.md)：将同一新闻解释镜头做成 16:9 与 9:16 两种排版，而非整体缩放。

## 能力边界

不是任意网页直接录屏就等价；具体 authoring contract 以当前官方文档为准。

## 使用建议（本词典编辑性判断）

- 先读官方 animation skill 和项目规范；让 CSS、JS、媒体跟随同一显式时间。
- 先确定画幅、帧率与音轨；同一镜头不同时间单独检查。

## 时间线与输出

显式帧时间或框架官方渲染时间线。

使用框架输出，或帧序列 → FFmpeg。

## 进一步辨别

### 先看契约，而不是只看 HTML

画面可以由 DOM、Canvas 或 WebGL 构成，但离线渲染需要一个稳定的时间入口。动画开始前字体、模型、纹理和媒体应已准备好。库内部的真实时钟、随机数和异步加载是不同问题，不能只关闭 requestAnimationFrame 就认为全部解决。

### 本词典建议的辨别实验

先制作同一 4 秒镜头的纯 SVG 版本和含一段媒体的版本。分别检查跳到 2 秒、从头播放到 2 秒、跳到 3 秒再退到 2 秒时是否一致。若不同，定位状态历史或媒体解码依赖，不直接归因为模型弱。

官方入口：[架构复盘](https://www.heygen.com/research/html-to-video)、[animation skill](https://github.com/heygen-com/hyperframes/blob/main/skills/hyperframes-animation/SKILL.md)、[开发者入口](https://hyperframes.heygen.com/developers)。官方 contract 可能变化，动手前再核对。
