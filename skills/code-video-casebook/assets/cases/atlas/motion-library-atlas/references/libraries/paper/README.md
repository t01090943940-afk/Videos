# Paper.js

> 类型：矢量库 · 分类：矢量与手绘 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

提供 Canvas 上的矢量场景与路径几何操作。

- 贝塞尔曲线
- 路径运算
- 场景层级
- 交互工具

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：做一张不断重排的纸片切割海报。
- [实验方向 02](./examples/02.md)：让生长曲线沿障碍物轮廓展开，作为解释性的路径动画。

## 能力边界

Canvas 路径对象不等于原生 SVG DOM；逐帧导出需自行组织。

## 使用建议（本词典编辑性判断）

- 把几何计算与运动时序分离；复杂运算可预计算路径。
- 核对路径身份、方向、孔洞、viewBox 与中间帧。

## 时间线与输出

形状与笔触先准备，运动由 t 或受控时间线求值。

SVG 渲染或 Canvas 捕获。

## 组合候选

[gsap](../gsap/README.md), [rough](../rough/README.md), [flubber](../flubber/README.md), [svg](../svg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 随机手绘每帧重生成会变成闪烁，不是质感。
