# Apache ECharts

> 类型：图表库 · 分类：数据与图解 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

丰富图表与数据更新动效，含跨类型通用过渡。

- 图表
- 数据更新
- universalTransition
- Canvas SVG

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：用相同数据从分布图过渡到汇总图。
- [实验方向 02](./examples/02.md)：让分组关系通过图形重组显露，而不是突然换图。

## 能力边界

通用过渡需要数据对象对应关系；渲染器和导出需验证，不能把它视为任意形状 morph。

## 使用建议（本词典编辑性判断）

- 固定 series 和数据身份；检查中间态是否改变含义；保留坐标和单位。
- 标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 时间线与输出

固定数据与对象身份，显式插值几何或视图信号。

SVG/Canvas 捕获 → 视频合成。

## 组合候选

[d3](../d3/README.md), [svg](../svg/README.md), [remotion](../remotion/README.md), [observable-plot](../observable-plot/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 高级图形不是把所有数字同时翻滚。
