# Anime.js

> 类型：动画库 · 分类：时间与编排 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

面向 JS 对象、DOM 与 SVG 的动画编排工具。

- timeline
- SVG 动画
- stagger
- WAAPI 工具

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让一组几何印章按声音重音依次落下。
- [实验方向 02](./examples/02.md)：将一条 SVG 曲线的描边、标签与节点高亮同步。

## 能力边界

不同大版本 API 不同；看到旧教程应先核对版本。

## 使用建议（本词典编辑性判断）

- 显式定义动画开始状态；不要让自动播放与离线逐帧时间同时驱动对象。
- 把入场、强调、停留与退出分开；静止可以是有意阅读，不等于故障。

## 时间线与输出

暂停内部自动播放，显式设置当前时间；必要时预采样。

DOM/SVG 截图或 Canvas 帧 → 编码。

## 组合候选

[gsap](../gsap/README.md), [waapi](../waapi/README.md), [svg](../svg/README.md), [canvas2d](../canvas2d/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 缓动要符合物体与叙事功能，不是所有对象都弹簧。
