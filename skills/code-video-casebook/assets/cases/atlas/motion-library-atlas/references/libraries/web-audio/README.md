# Web Audio API

> 类型：浏览器 API · 分类：声音与节拍 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

音频节点图、合成、分析和离线渲染的原生接口。

- AudioContext
- OfflineAudioContext
- 频谱
- 节点连接

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：用同一事件时间表驱动打击声和图形撞击。
- [实验方向 02](./examples/02.md)：分析一段音频的能量并映射到有限的视觉参数。

## 能力边界

音频时钟与画面时钟不同；设备播放延迟不能直接作为视频同步依据。

## 使用建议（本词典编辑性判断）

- 优先离线渲染音轨；记录采样率；避免削波并测试声画对齐。
- 分开 BGM、旁白、音效与静默；控制响度、削波和版权。

## 时间线与输出

最终音轨用离线采样时间；实时播放只作预览。

WAV/音频数据 → 与视频混合编码。

## 组合候选

[tone](../tone/README.md), [midi](../midi/README.md), [ffmpeg](../ffmpeg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 音乐合成与 AI 作曲不是一回事，节拍不能覆盖旁白可理解性。
