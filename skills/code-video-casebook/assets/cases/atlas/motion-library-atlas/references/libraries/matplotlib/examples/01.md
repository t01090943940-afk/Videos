# Matplotlib Animation · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把两个频率的波形叠加展示成可读的拍频。

## 需要调用的能力

FuncAnimation, 科学坐标, 多曲线更新, writer 导出。

## 先检查什么

绘图风格不是自动形成的 MG 风格；与 Manim 不是同一种库。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

预先确定坐标范围和数据；避免每帧重新创建所有 Artist；以实际编码结果验收。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
