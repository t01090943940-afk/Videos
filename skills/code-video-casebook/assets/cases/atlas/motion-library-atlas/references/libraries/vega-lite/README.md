# Vega-Lite

> 类型：声明式语法 · 分类：数据与图解 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

以精简配置表达统计图和组合视图。

- encoding
- transform
- 复合视图
- 参数

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：快速枚举同一论点的多种图表表达再选最清楚的一种。
- [实验方向 02](./examples/02.md)：在比较镜头中保持相同量纲与视觉比例。

## 能力边界

较低层的逐元素动作不如手写场景自由；不是替代所有 D3 图解。

## 使用建议（本词典编辑性判断）

- 先生成正确图形，再决定镜头切换；不要为复杂动效扭曲数据编码。
- 标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 时间线与输出

固定数据与对象身份，显式插值几何或视图信号。

SVG/Canvas 捕获 → 视频合成。

## 组合候选

[d3](../d3/README.md), [svg](../svg/README.md), [remotion](../remotion/README.md), [observable-plot](../observable-plot/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式
