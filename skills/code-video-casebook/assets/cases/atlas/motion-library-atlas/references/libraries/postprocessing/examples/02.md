# postprocessing · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

将颜色分级与光晕统一到产品镜头的视觉语言。

## 需要调用的能力

effect passes, bloom, 景深, 组合效果。

## 先检查什么

后期不能挽救错误布光；色彩空间与 tone mapping 要匹配。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

先关闭后期验证基础画面；逐项添加并对照成本和可读性。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
