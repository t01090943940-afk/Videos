# Apache ECharts · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

让分组关系通过图形重组显露，而不是突然换图。

## 需要调用的能力

图表, 数据更新, universalTransition, Canvas SVG。

## 先检查什么

通用过渡需要数据对象对应关系；渲染器和导出需验证，不能把它视为任意形状 morph。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

固定 series 和数据身份；检查中间态是否改变含义；保留坐标和单位。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
