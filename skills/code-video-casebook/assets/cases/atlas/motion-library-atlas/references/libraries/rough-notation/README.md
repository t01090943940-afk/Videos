# Rough Notation

> 类型：标注库 · 分类：矢量与手绘 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

为 DOM 元素加手绘感高亮、下划线和括号。

- 圈注
- 下划线
- 高亮
- 组播放

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：给截图上的一个证据数字画圈。
- [实验方向 02](./examples/02.md)：通过连续括号建立文段中的因果分组。

## 能力边界

依赖元素布局；截图前文字换行会改变标注边界。

## 使用建议（本词典编辑性判断）

- 冻结布局后测量；把标注的开始点对准讲解重音。
- 核对路径身份、方向、孔洞、viewBox 与中间帧。

## 时间线与输出

形状与笔触先准备，运动由 t 或受控时间线求值。

SVG 渲染或 Canvas 捕获。

## 组合候选

[gsap](../gsap/README.md), [rough](../rough/README.md), [flubber](../flubber/README.md), [svg](../svg/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 随机手绘每帧重生成会变成闪烁，不是质感。
