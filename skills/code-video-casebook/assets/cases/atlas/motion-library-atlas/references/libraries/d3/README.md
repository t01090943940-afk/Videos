## 它增加了什么能力

将数据映射到尺度、形状、布局和 DOM。

- scales
- shapes
- data join
- 布局算法

## 能力边界

D3 不是视频渲染器；transition 的真实时间不天然等于视频时间。本地附带案例使用 D3 3.x，不代表现行 API 验证。

## 使用建议（本词典编辑性判断）

- 给数据稳定 key；先算布局，再用统一时间插值几何；标明数据是否合成。
- 标注单位、来源与示例数据；保持坐标语义，不能为好看误导数据。

## 时间线与输出

固定数据与对象身份，显式插值几何或视图信号。

SVG/Canvas 捕获 → 视频合成。

## 进一步辨别

### 数据身份决定动画是否可读

排名变化需要保留每个实体的身份，不能在排序后把数组第 1 项当作同一个对象。数值、位置与颜色的变化应有稳定对应。

科学或新闻视频还需保留单位、时间、数据来源与分母。动画可能让变化看起来更戏剧化，因此要检查轴范围是否在过程中偷偷改变。

本工作站的 d3-arcs 使用现有离线 D3 3.x 的 arc API；其余图表是 Canvas 原理例。这里没有把旧版本示例称为 D3 7 兼容性测试。[现行官方入口](https://d3js.org/)。
