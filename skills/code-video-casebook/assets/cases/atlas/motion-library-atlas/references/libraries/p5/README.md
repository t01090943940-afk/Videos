# p5.js

## 它增加了什么能力

提供绘图、噪声、交互和 WebGL 的创意编程入口。

- 2D 绘画
- noise
- WEBGL
- shader

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让噪声流场变成逐渐聚拢的字形。
- [实验方向 02](./examples/02.md)：将手绘笔触与几何结构对照，解释有序与随机。

## 能力边界

draw 的帧计数不是可靠视频时钟；随机、鼠标和实时输入需冻结。

## 使用建议（本词典编辑性判断）

- 用明确 t 代替 frameCount 累积状态；固定 seed；将输入录制或参数化。
- 选择一到两个主参数；先保证构图再提高粒子数量。

## 时间线与输出

固定随机种子；累计模拟预计算或从零复算。

Canvas/WebGL 帧捕获。

## 组合候选

[webgl](../webgl/README.md), [canvas-sketch](../canvas-sketch/README.md), [canvas-record](../canvas-record/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 噪声、粒子和故障风不应没有语义地常驻画面。

## 进一步辨别

### 将交互草图变成可拍摄对象

先把鼠标、麦克风与滚动输入改为可保存的轨迹。纯函数几何可以直接按 t 求值；会积累状态的粒子、反馈纹理或画笔不能简单倒放时钟，需要缓存或从初态模拟。

随机种子只解决随机序列的可复现，不能自动解决不同执行次数引起的状态差异。一个有效实验是先向前跳，再回退到同一时刻，比较画面。

[p5 reference](https://p5js.org/reference/) 提供绘图能力；[社区 paint skill](https://github.com/heygen-com/hyperframes-community-skills) 提供另一层工作方式。两者都不能替代对成片的观看。
