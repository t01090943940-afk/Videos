# WebGL

> 类型：浏览器 API · 分类：着色与后期 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

浏览器 GPU 图形接口，可绘制自定义二维或三维效果。

- shader
- textures
- framebuffer
- GPU 绘制

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让两个镜头通过程序化位移场互相显露。
- [实验方向 02](./examples/02.md)：实现一个只有几何与光影的抽象产品片头。

## 能力边界

上限高但实现成本高；驱动差异、精度和上下文丢失需处理。

## 使用建议（本词典编辑性判断）

- 显式尺寸与时间 uniform；检查 shader 编译日志；同环境验证帧可重复性。
- 检查编译、长宽比、颜色空间、设备支持、内存和上下文丢失。

## 时间线与输出

显式时间 uniform；反馈效果需保存状态或预计算。

framebuffer/Canvas → 序列或编码。

## 组合候选

[gl-transitions](../gl-transitions/README.md), [pixi-filters](../pixi-filters/README.md), [postprocessing](../postprocessing/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 全屏炫光会遮蔽主体；转场必须有方向或形状联系。
