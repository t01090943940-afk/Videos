## 能力边界

能力广不代表 AI 能一次可靠完成复杂角色片；计算预算与资产质量仍决定效果。

## 使用建议（本词典编辑性判断）

- 固定版本与资产；先做低采样 animatic；烘焙模拟；按镜头检查接触与遮挡。
- 资产、作品、软件和网站 API 的许可证是不同层；执行第三方脚本前审查。

## 时间线与输出

DCC 使用场景帧与缓存，资产工具记录配置和原始文件。

GLB / 序列帧 / EXR / 剪辑交换文件。

## 进一步辨别

### 好模型不是好镜头的充分条件

先把摄影机、主光、地面接触和主体比例调清楚。渲染质量可以逐级增加，但若轮廓不清、动作没有因果，再高采样也不会变成好视频。

一个可复用片场可以只包含少量优质模型与几个机位。资产导入后检查单位、朝向、材质贴图、法线和关节姿态。动画模拟先烘焙，最终按 shot 输出帧序列。

[Python API](https://docs.blender.org/api/current/index.html) 提供脚本控制，[社区 MCP](https://github.com/ahujasid/mcp-for-blender) 提供外部代理接入。MCP 是执行通道，不是建模质量保证。
