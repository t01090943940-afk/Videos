# tsParticles

> 类型：粒子库 · 分类：生成艺术 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

用配置组织粒子发射、交互和预设效果。

- 粒子
- 发射器
- 交互
- 形状预设

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让粒子从一个论点扩散并聚成下一镜的图形。
- [实验方向 02](./examples/02.md)：用密度变化表达集中与分散，而非纯烟花装饰。

## 能力边界

网页交互和随机粒子不天然可 seek；大量插件会增加依赖复杂度。

## 使用建议（本词典编辑性判断）

- 只加载所需插件；确认随机种子和时间控制；避免将粒子背景用于所有镜头。
- 选择一到两个主参数；先保证构图再提高粒子数量。

## 时间线与输出

固定随机种子；累计模拟预计算或从零复算。

Canvas/WebGL 帧捕获。

## 组合候选

[p5](../p5/README.md), [webgl](../webgl/README.md), [canvas-sketch](../canvas-sketch/README.md), [canvas-record](../canvas-record/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 噪声、粒子和故障风不应没有语义地常驻画面。
