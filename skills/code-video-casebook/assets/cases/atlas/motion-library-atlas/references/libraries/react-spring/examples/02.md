# React Spring · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把数据变化作为弹性形变，而非所有元素使用同一 ease。

## 需要调用的能力

弹簧, 插值, 链式动画, 多目标值。

## 先检查什么

实时弹簧求解与离线 seek 不天然等价；同一输入需固定初值与采样策略。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

先区分交互反馈和成片演出；录制或预采样弹簧轨迹后再逐帧使用。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
