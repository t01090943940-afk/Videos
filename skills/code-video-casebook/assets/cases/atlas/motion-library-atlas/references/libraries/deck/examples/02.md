# deck.gl · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把地理分布转成可读的三维柱体，控制透视误差。

## 需要调用的能力

数据图层, GPU 聚合, 地理轨迹, 3D 标记。

## 先检查什么

不是底图服务；数据规模、精度和叠加方式需评估。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

稳定数据对象与图层 ID；将事实数据和演示数据明确分开。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
