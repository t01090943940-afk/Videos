# visx · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把图表拆为可独立运动的轴、数据和注释。

## 需要调用的能力

scales, shapes, axes, React 组件。

## 先检查什么

偏底层组合，AI 仍需做布局与动画决策；不等于开箱即用导演模板。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

让 React 帧状态生成图形属性；保留 scale 域避免每帧跳轴。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
