# Spine Runtimes

> 类型：骨骼运行时 · 分类：角色与动画资产 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

播放 Spine 制作的二维骨骼动画。

- 骨骼
- 动画混合
- 皮肤
- 网格变形

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：用可复用角色动作构建短篇叙事。
- [实验方向 02](./examples/02.md)：让同一套骨骼换装后服务不同场景而不重做动作。

## 能力边界

运行时许可与编辑器许可相关；不能当作完全无门槛的免费素材系统。

## 使用建议（本词典编辑性判断）

- 核对编辑器和 runtime 版本；记录皮肤和动画依赖；固定时间步。
- 动画资产、字体、贴图和 runtime 分别核对版本及授权。

## 时间线与输出

暂停自动播放；固定帧或重放状态输入事件。

运行时捕获 → 合成。

## 组合候选

[lottie](../lottie/README.md), [rive](../rive/README.md), [remotion](../remotion/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式
