# Pretext

> 类型：排版库 · 分类：文字与排版 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

快速测量和布局文本，为自定义排版提供几何信息。

- 文字测量
- 换行布局
- 预处理缓存
- 自定义布局

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：让文字沿可读的轮廓排布，再按语义分组揭示。
- [实验方向 02](./examples/02.md)：在字幕区宽度变化时保持稳定换行，避免逐帧抖动。

## 能力边界

它不是文字动画引擎，也不会自动做 kinetic typography；仍依赖可用字体。

## 使用建议（本词典编辑性判断）

- 先准备字体与文本；复用测量结果；动画由其他库控制，布局与绘制分离。
- 用实际字体检查最长文案；中文字数与英文单词不能用同一测量假设。

## 时间线与输出

先固定字体和排版，再给字符或语义分组赋时间。

SVG/DOM 捕获或轮廓绘制 → 帧序列。

## 组合候选

[canvas2d](../canvas2d/README.md), [svg](../svg/README.md), [gsap](../gsap/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 整段文字持续抖动、飞散和扰乱，会损害理解。

## 进一步辨别

### 这是排版基础，不是动效预设

它有价值的地方，是让自定义文字布局更容易获得度量和换行结果。一个空间不断变化的文本容器，仍需决定是否保持行结构、是否重排以及重排时怎样保留阅读连续性。

建议用中文长标题、英文长词、数字和混合标点做四组样例。冻结字体、字号与可用宽度后再测试动画。即使测量足够快，每一帧重新换行也未必有视觉价值。

[作者仓库](https://github.com/chenglou/pretext) 用于核对能力；本地排版例是 Canvas 的简化测量演示，不是 Pretext 性能测试。
