# Anime.js · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

将一条 SVG 曲线的描边、标签与节点高亮同步。

## 需要调用的能力

timeline, SVG 动画, stagger, WAAPI 工具。

## 先检查什么

不同大版本 API 不同；看到旧教程应先核对版本。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

显式定义动画开始状态；不要让自动播放与离线逐帧时间同时驱动对象。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
