# MCP for Blender · 实验方向 02

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

搜索合法低多边形资产后统一尺度并布置场景。

## 需要调用的能力

对象操作, 场景查询, 代码执行, 资产整合。

## 先检查什么

不是 Blender 官方；代码执行、外网访问与可能计费服务有风险。仓库已使用 mcp-for-blender 名称，旧链接可能重定向。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

审查工具权限；隔离工程与凭证；先保存副本；外部资产与执行脚本需确认。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
