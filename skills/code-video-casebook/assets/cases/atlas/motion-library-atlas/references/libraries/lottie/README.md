# Lottie Web

> 类型：动画运行时 · 分类：角色与动画资产 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

播放由支持工具导出的矢量动画数据。

- 动画播放
- 帧定位
- SVG Canvas
- AE 生态衔接

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：在代码视频中复用设计师制作的矢量角色动作。
- [实验方向 02](./examples/02.md)：将一个复杂图标动画作为镜头中的局部组件。

## 能力边界

不支持全部 AE 特性；拥有播放器不代表能生成所有原始设计。

## 使用建议（本词典编辑性判断）

- 先检查支持特性；暂停并用帧控制；保留源工程与素材授权。
- 动画资产、字体、贴图和 runtime 分别核对版本及授权。

## 时间线与输出

暂停自动播放；固定帧或重放状态输入事件。

运行时捕获 → 合成。

[rive](../rive/README.md), [spine](../spine/README.md), [remotion](../remotion/README.md)。组合关系仅是研究候选，不代表已验证兼容。
