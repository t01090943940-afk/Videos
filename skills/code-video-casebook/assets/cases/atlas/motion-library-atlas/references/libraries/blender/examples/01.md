# Blender · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

搭一套可复拍的微缩摄影棚，镜头脚本与场景文件分离。

## 需要调用的能力

建模, 骨骼, 摄影机, 渲染合成。

## 先检查什么

能力广不代表 AI 能一次可靠完成复杂角色片；计算预算与资产质量仍决定效果。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

固定版本与资产；先做低采样 animatic；烘焙模拟；按镜头检查接触与遮挡。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
