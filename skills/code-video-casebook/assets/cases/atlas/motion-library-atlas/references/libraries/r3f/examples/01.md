# React Three Fiber · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

把灯光、人物、道具拆成可替换组件。

## 需要调用的能力

声明式场景, 组件复用, hooks, Three 生态。

## 先检查什么

不是独立于 Three 的新渲染引擎；useFrame 默认依赖实时循环。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

分离静态资源与逐帧属性；离线捕获时禁用非确定自动更新。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
