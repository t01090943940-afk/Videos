# Pretext · 实验方向 01

**状态：原创设计建议；非官方作品或已完成实验**

## 想表达什么

让文字沿可读的轮廓排布，再按语义分组揭示。

## 需要调用的能力

文字测量, 换行布局, 预处理缓存, 自定义布局。

## 先检查什么

它不是文字动画引擎，也不会自动做 kinetic typography；仍依赖可用字体。

## 实验建议

先做一个足够短的代表镜头；固定素材与时长。对比一个朴素方案和一个有目的的变化方案。记录技术完成度和视觉价值，勿将更多运动视为更高质量。

先准备字体与文本；复用测量结果；动画由其他库控制，布局与绘制分离。

## 验收

能定位到明确时间；首尾与中间帧可见；关键文字可读；非意图重叠有检查；音视频输出信息正确。失败时记录原因，不伪造通过。
