# regl

> 类型：WebGL 库 · 分类：生成艺术 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

把 WebGL 绘制状态封装成声明式命令。

- draw command
- uniforms
- buffers
- framebuffer

## 值得尝试的表达

以下是原创实验建议，不是声称已找到或复刻的官方获奖作品。

- [实验方向 01](./examples/01.md)：用成千上万条线描述同一个向量场。
- [实验方向 02](./examples/02.md)：以两次渲染 pass 完成反馈纹理视觉实验。

## 能力边界

仍需要图形学知识；不负责模型、摄影和高级场景管理。

## 使用建议（本词典编辑性判断）

- 固定资源并只更新 uniforms；检查状态隔离和 framebuffer 尺寸。
- 选择一到两个主参数；先保证构图再提高粒子数量。

## 时间线与输出

固定随机种子；累计模拟预计算或从零复算。

Canvas/WebGL 帧捕获。

## 组合候选

[p5](../p5/README.md), [webgl](../webgl/README.md), [canvas-sketch](../canvas-sketch/README.md), [canvas-record](../canvas-record/README.md)。组合关系仅是研究候选，不代表已验证兼容。

## 常见平庸与失败模式

- 噪声、粒子和故障风不应没有语义地常驻画面。
