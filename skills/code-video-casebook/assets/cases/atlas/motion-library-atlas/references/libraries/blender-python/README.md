# Blender Python API

> 类型：脚本接口 · 分类：专业工具与资产 · 研究快照：2026-09-24
> 证据：官方资料核对核心定位。本条不包含跨模型成绩；关联原理演示不视为该库实测。

## 它增加了什么能力

用 bpy 访问场景数据、属性、操作器和渲染。

- bpy.data
- 关键帧
- 渲染调用
- 场景管理

- [实验方向 02](./examples/02.md)：自动检查场景对象命名、相机范围与缺失资源。

## 能力边界

bpy.ops 依赖上下文；不是普通 Python 环境安装即等同完整 Blender。

## 使用建议（本词典编辑性判断）

- 优先明确数据引用；避免无谓选择操作；脚本运行前保存工程副本。
- 资产、作品、软件和网站 API 的许可证是不同层；执行第三方脚本前审查。

## 时间线与输出

DCC 使用场景帧与缓存，资产工具记录配置和原始文件。

GLB / 序列帧 / EXR / 剪辑交换文件。
