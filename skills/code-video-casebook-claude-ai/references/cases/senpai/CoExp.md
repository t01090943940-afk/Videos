# 代码视频制作复盘：《中秋 · 给学姐》

> 成片：29 秒 · 1080×1920 竖屏 · 30fps · H.264 + AAC · 约 6MB
> 画面、配乐、字幕全部由代码生成，没有用任何素材、剪辑软件或 AI 生图/生音。
> 共做了两版：V1（“拆解焦虑”，被否）→ V2（“她是一束光”，定稿）。

---

## 一、核心方法

### 1.1 总体管线

```
scene.html (Canvas 2D, render(t) 纯函数)
      │  Playwright 无头 Chromium，逐帧设定 t → 截图 PNG
      ▼
frames/f0000.png … f0869.png
      │                         audio.py (numpy 合成 + 卷积混响) → music.wav
      ▼                                   │
ffmpeg  (libx264 crf18 yuv420p + aac 192k, -shortest, +faststart)
      ▼
成片.mp4
```

每个环节只做一件事，互相之间用文件交接，所以任何一环都可以单独重跑。

### 1.2 关键设计：`render(t)` 是纯函数

整个视频就是一个函数：**给一个时间 t（秒），画出这一刻的完整画面**。它不依赖上一帧，也不依赖 `requestAnimationFrame`，只依赖 t。

这个选择带来四个好处：

| 好处 | 具体表现 |
|---|---|
| 帧精确 | 不存在实时渲染掉帧、时间漂移，30fps 就是严格的 i/30 秒 |
| 可并行 | 开 2 个页面，一个渲偶数帧、一个渲奇数帧 |
| 可局部重渲 | V2 只改了兔子的爪子，只重渲 23.3 秒之后的 170 帧，不用全部重来 |
| 可抽帧预览 | 想看第 17.5 秒，直接 `render(17.5)` 截一张，不用播到那里 |

要让它成立，**随机数必须是种子固定的**（用 mulberry32 PRNG），星星、桂花、灯笼位置每一帧都一样。

### 1.3 时间控制的三个小工具

整个动画只靠三个函数驱动，没用任何动画库：

```js
const seg = (t,a,b) => clamp((t-a)/(b-a));        // t 在 [a,b] 里走到了百分之几
const eio = x => x<.5 ? 4*x*x*x : 1-Math.pow(-2*x+2,3)/2;  // 缓入缓出
const win = (t,a,b,fi,fo) => Math.min(eout(seg(t,a,a+fi)), 1-seg(t,b-fo,b)); // 出现窗口：淡入→停留→淡出
```

任何动画都写成：`位置 = lerp(起点, 终点, eio(seg(t, 开始秒, 结束秒)))`。
所有元素的“剧本”就是一堆时间区间，改节奏只需要改数字。

### 1.4 帧捕获

```js
await page.goto('file:///.../scene2.html');
await page.evaluate(() => window.ready);            // 等中文字体加载完
for (let i = w; i < N; i += P) {
  await page.evaluate(t => render(t), i / FPS);
  await page.screenshot({ path: `frames2/f${String(i).padStart(4,'0')}.png` });
}
```

- 视口直接设成 1080×1920，canvas 同尺寸，截图即成帧。
- 870 帧、2 核、2 个页面并行，约 6 分钟。

### 1.5 配乐：用 numpy 写出来

不用任何音频素材，四种“乐器”全是公式：

| 乐器 | 实现 | 用在哪 |
|---|---|---|
| pad（铺底和弦） | 正弦 + 二次谐波，左右各微失谐 ±0.1 音分，慢起慢收 | 每一幕换一个和弦，定情绪底色 |
| pluck（拨弦） | 指数衰减的正弦 + 快速衰减的高次谐波 | 旋律、点灯音、兔子跳 |
| bell（钟） | 非整数倍泛音（1, 2.76, 5.4, 8.9），各自衰减 | 月圆的高光时刻 |
| 混响 | 与“指数衰减白噪声”做卷积（fftconvolve），干湿 62:38 | 全曲统一空间感 |

**画面和音乐共享同一张时间表**。例如：她点亮第 i 盏灯的时刻，是用和画面完全相同的缓动公式反算出来的，再在那个时刻放一个音。所以音画是“算”对齐的，不是“听”对齐的。

### 1.6 检查方法：联系表（contact sheet）

每次改完不渲整片，只抽 4～9 个关键时间点截图，用 PIL 拼成一张大图一眼看完。
细节问题（比如月饼上的字）要**裁原图局部放大看**，缩略图会把问题藏起来。

## 二、以这个视频为模板的经验

### 2.1 V2 的完整结构（可直接当模板套）

| 幕 | 时间 | 画面 | 字幕 | 情绪任务 |
|---|---|---|---|---|
| 1 认可 | 0–5.2s | 一束暖光在山坡上独自前行，天上一弯细月牙 | 学姐，中秋快乐呀。/ 这一路，你走得很稳，也很勇敢。 | 先叫名字、先祝福，再肯定她 |
| 2 看见 | 5.2–10.8s | 她走过的地方灯一盏盏亮起，远山的灯像涟漪一样接连亮起 | 你总是先把光，分给别人。/ 谁需要帮忙，你就在。 | 说出她最在乎的那个自己（乐于助人、影响更多人） |
| 3 回流 | 10.8–16.6s | 所有灯变成孔明灯飞回来，环绕着她，她的光变亮 | 今晚，换它们来照亮你。/ 你给出去的温柔，都在回来的路上。 | 全片情绪最高点：一直给予的人，这次被照顾 |
| 4 相信 | 16.6–22.8s | 孔明灯升空把月牙补成满月，月光铺成一条路落到她脚下 | 你想让这个世界，更公平一点。/ 这条路，月光会一直替你照着。/ 你会成为，很好很好的法律人。 | 把“考研”升格成“她想成为的人”，给勇气 |
| 5 快乐 | 22.8–29s | 月亮迸出光点、桂花落下、“中秋快乐！”、玉兔抱着“上岸”月饼蹦进来 | 月饼要吃甜的，上岸要稳稳的。/ 冲呀，学姐！/ 千里共婵娟 · 你不是一个人在努力 | 情绪从感动切到开心，看完是笑着的 |

**情绪曲线：认可 → 看见 → 被照顾 → 相信 → 快乐。**
前四幕往“深”走，第五幕往“亮”走。结尾一定要把人从感动里拉出来，否则看完是沉的。

### 2.2 一条贯穿全片的视觉线

月亮从第 0 秒的细月牙，随着她前进慢慢变圆；最后是**她点亮过的那些灯**飞上去把月亮补满。

- 这条线让 5 幕不是 5 张 PPT，而是一件事的 5 个阶段。
- 中秋元素不是贴上去的装饰，而是叙事本身：月圆 = 她的付出汇聚起来的结果。
- 实现方式：离屏 canvas 画满月，再用 `destination-out` 挖掉一个偏移的圆，偏移量 `d` 从 `2r·0.22`（细月牙）插值到 `2.3r`（完全挖不到 = 满月）。

### 2.3 字幕系统：统一骨架

- 固定在底部一条带（y = 1530 / 1614 / 1698），每幕最多 3 行。
- 同一套进场方式：淡入 0.55s + 上浮 18px，淡出 0.45s。
- 颜色只有两个意思：米白 = 陈述，金色 = 这一幕的重点句。
- 同一幕里后一行比前一行晚 1.6～1.8 秒出现，给阅读留时间。
- **经验值：中文一行 ≈ 2 秒阅读时间；30 秒视频最多放 12～13 行字幕。**

画面主体始终在字幕带之上（地平线约 y=1300），字幕永远不压画面。

### 2.4 配色

| 名称 | 值 | 用途 |
|---|---|---|
| 夜空顶 | `#070a1d` | 背景渐变起点 |
| 夜空中 | `#121a40` → `#232760` | 天际线附近提亮，拉出纵深 |
| 月金 | `#f7d68f` | 重点字、月亮、光 |
| 灯橙 | `#ffb869` | 孔明灯、暖光晕 |
| 米白 | `#f5ecd9` | 正文、兔子 |

冷底（蓝紫夜空）+ 暖光（金橙），全片只有这一对对比。月亮变圆时，全屏再叠一层暖色径向光，整体色温随情绪升高。

### 2.5 可复用的“质感”小技巧

- **光晕**：同一位置叠 2～3 层不同半径的径向渐变，比 `shadowBlur` 更柔、更可控。
- **灯笼闪烁**：两个不同频率的正弦相乘，`.85 + .15*sin(9t)*sin(5.3t)`，不规则但不抖。
- **行走感**：光点前进时加 `|sin(5.2t)|` 的小弹跳，停下后换成慢呼吸。
- **兔子蹦跳**：`|sin(k·π·3)|` 产生 3 次跳，地面阴影随高度缩小。
- **远近层次**：两层山（近山深、远山稍亮），远处的灯尺寸 ×0.55～0.8。
- **首尾**：全局 0.5s 黑场淡入、0.6s 淡出；音乐 0.6s 淡入、1.6s 淡出。

### 2.6 交付

- 本地 MP4 用 `+faststart`，微信、网页都能边下边播。
- 发成网页时视频文件改成 ASCII 文件名（`moon.mp4`），中文和 `·` 放进 URL 容易出问题。
- 网页只能在线看，**下载要单独发文件**，两种方式都要准备好。

## 三、踩过的坑

按“对最终效果的影响”从大到小排。

### 3.1 最大的坑：理解错了“要什么”（导致 V1 整版重做）

- **现象**：V1 把“系统性缓解焦虑”理解成“帮她把考研拆清楚”，画面里出现了刑法学、民法学、法理学等五门课的表格和“每天一格”的进度格子。用户反馈“扯到知识这里有些怪怪的”。
- **根因**：
  1. 没有问清楚**送的人和收的人是什么关系**。学弟送学姐的是祝福和心意，不是学习方法。
  2. 把“系统性”理解成了“逻辑结构化”，而用户要的是“情绪上完整地接住她”。
  3. 信息太少时，默认用了自己最擅长的“讲道理”方式。
- **教训**：祝福类视频开工前至少要确认三件事：**谁送给谁、两人什么关系、看完希望她是什么感觉**。这三件事决定整片调性，比技术细节重要一百倍。

### 3.2 敏感背景信息的边界

- 用户提供了对方较私人的背景，并明确要求画面中不要出现相关内容。
- 做法：背景只用来**决定调性**（她一直在给予，所以核心是“这次换别人照顾你”），不进任何画面和字幕。
- 连带避开了中秋最常见的“团圆”“回家”等词。即使是好意，这类词也可能刺痛对方。
- **教训**：私人信息应该影响“怎么说”，不应该出现在“说什么”里。

### 3.3 视觉效果的坑

| 坑 | 现象 | 修法 |
|---|---|---|
| 暗月像灰色圆盘 | V2 初稿想让月亮“暗着等被点亮”，结果成了一个脏灰色圆饼，还加了一条横向遮罩带，更难看 | 改成细月牙逐渐变满月，本身就是中秋意象，比“变亮”更好懂 |
| 月相公式写反 | `d = 2r(1-ph)`，ph 小时反而接近满月 | 改成 `d = 2r·ph`。**凡是“越来越…”的参数，先代两个端点值验算** |
| 混乱文字不够“乱” | V1 焦虑词字号小、透明度低，看起来不压迫 | 字号放大 1.35 倍，范围铺满，焦虑词不透明度提到 0.7 |
| 文字被裁出画面 | “还剩几个月”随机落在右边缘被切掉 | 随机位置要减去文字宽度，横坐标限制在 230～850 |
| 兔爪挡住月饼上的“上岸” | 缩略图里看不出来，放大才发现 | 爪子下移到月饼下沿；**关键文字必须裁原图放大检查** |

### 3.4 代码与工程的坑

| 坑 | 说明 | 教训 |
|---|---|---|
| 变量遮蔽 | 局部 `const lift = 数字` 遮住了同名函数 `lift(t)`，之后调用 `lift(t)` 会直接抛错 | 局部变量和函数不要重名，本次改成 `liftV` |
| 错误监听挂晚了 | `page.on('pageerror')` 写在 `goto` 之后，加载阶段的错误会漏掉 | 监听要在 `goto` 之前挂 |
| 字体未就绪 | Canvas 用系统字体，前几帧可能是回退字体 | `document.fonts.load()` 两个字重都等完，再开始截帧 |
| 旧帧残留 | 帧目录复用时，如果新版本更短，多出来的旧帧会被 ffmpeg 一起编码进去 | 每个版本用新目录（frames2），或者渲染前清空 |
| 音画时长 | 视频 29s、音频也必须 29s | 两边共用 `DUR` 常量，ffmpeg 加 `-shortest` 兜底 |
| 截错检查区域 | 第一次裁切放大时坐标算错，裁到了空白 | 先在联系表里定位，再换算回 1080×1920 坐标 |
| 渲染耗时 | PNG 截图约 0.4s/帧，2 核跑 870 帧约 6 分钟 | 预览只抽关键帧；改局部只重渲受影响的帧区间 |

### 3.5 交付的坑

- **“链接”有歧义**：用户第一次要“视频链接”，我给了在线播放页；用户其实要的是下载。网页的沙盒会拦截下载，所以最后改为直接发文件。**以后应该一次把“在线看的链接”和“下载文件”都给出来。**
- **网页默认私有**：发给学姐前，需要在页面的 Share 菜单里打开分享，否则她打不开。
- **声音**：网页不能自动带声音播放，页面上要写“建议开声音”。

### 3.6 内容的坑（避开了，但值得记下）

- 考研具体日期不确定，所以不写倒计时天数。写错会很尴尬，而且精确的数字本身就会制造焦虑。
- “你一定能上岸”这类保证性的话不写，改成“你会成为很好的法律人”，肯定的是她这个人，不是一个结果。

## 四、做类似视频最重要的思路

### 4.1 深挖一个点：让她在画面里“成为”那个东西，而不是被告知

这是 V1 和 V2 最本质的区别，也是整个复盘里最值得记住的一条。

**V1 是“告诉她”**：焦虑是因为看不清 → 这是五门课 → 你已经走了很多 → 加油。
每一句都对，但她是观众，在看一个道理被讲出来。道理越对，越像一位老师，而不是一个关心她的人。

**V2 是“让她成为”**：画面里那束光就是她。她往前走，灯亮了；灯飞回来围着她；她的灯把月亮补圆了。
字幕只是在旁边轻轻说一句。她不需要被说服，她只是看见了自己。

为什么后者的力量大得多：

1. **情绪靠认同，不靠论证。** 人被“说服”时会下意识防御（“你又不懂我的情况”）；人“认出自己”时是放下防御的。第 2 幕“你总是先把光分给别人”之所以有力量，是因为画面先让她看到了这件事，字幕只是替她说了出来。
2. **隐喻让大事变得可以承受。** “你对社会有贡献”直接说出来是空话，甚至有压力；变成“远处的灯一片片亮起”，就成了一个可以看、可以感受的画面。隐喻给了情绪一个落点。
3. **因果闭环会产生“被回报”的感觉。** V2 里月亮变圆不是自己变圆的，是她点亮的灯飞上去补满的。这个因果让结尾的“中秋快乐”不是一句祝福语，而是**她自己挣来的**。对一个很坚强、一直自己扛、一直在给予的人，最打动她的不是“你辛苦了”，而是“你给出去的都算数，而且回来了”。
4. **节日意象要长在叙事里。** 同样是月亮，V1 里是背景装饰；V2 里月圆本身就是故事的结局。判断标准：把节日元素删掉，故事还成不成立？成立，说明它只是装饰。

**可操作的检验方法**：写完脚本后，遮住所有字幕，只看画面。如果画面自己能讲出这个故事，这个视频就成立了；如果离开字幕画面就是一堆好看的粒子，那还是在“讲道理”。

### 4.2 其他几条支撑性的思路

- **先定接收者，再定内容。** 谁送、送给谁、什么关系、看完是什么感觉。这四个答案决定 80% 的东西。
- **情绪曲线要先下沉、再上扬、最后落在“亮”上。** 感动之后必须有一个轻快的收尾（兔子、月饼、“冲呀”），让人笑着关掉视频，而且愿意再看一遍、转给别人。
- **称呼和口吻要像“这个人”在说话。** “学姐，中秋快乐呀”的“呀”，“很好很好的法律人”的叠词，是学弟的语气，不是贺卡的语气。
- **克制。** 30 秒只讲一件事、一个隐喻、一条视觉线。V1 同时讲了焦虑、结构、社会学底子、进度、月亮五件事，所以每件都很浅。
- **一个只属于她的细节，胜过十个通用的祝福。** “法律人”“更公平一点”“上岸月饼”，这些只对她成立的细节，才让她感觉这个视频是专门为她做的。
- **技术上保持“一个函数 + 一张时间表”。** 画面、字幕、音乐都从同一张时间表派生，改节奏只改数字。这让“内容推倒重来”的成本很低：V2 的内容完全重写了，但管线一行没改。
